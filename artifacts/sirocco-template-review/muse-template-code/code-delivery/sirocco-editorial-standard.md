# 시로코 검수 최상위 기준 (2026-10-13 사용자 확정)
교과서: https://thailivenow.com/ko/rooftops/sirocco/ (배포본 고정)

## 전달력 기준
템플릿 CSS/항목 일치가 아니라, 글을 읽고 "아 나도 가고 싶다" 느끼는 전달력이 기준.

## 문장 구조 (3단계)
1. 무엇이 매력인지 → 시설의 실제 풍경·특징·서비스
2. 누구와 가면 좋은지 → 동행 유형 (연인/가족/친구 등 실제 맞는 대상)
3. 어떤 시간/경험을 누릴지 → 방문 시간대·체류 방식·기대 경험

장단점은 선택에 도움되는 맥락에 배치 (예: "이런 여행에는 잘 맞고, 이런 날에는 고민해보세요").

## 반려 문체
- 조사메모/단답식 ("~입니다", "~확인됨")
- "알아서 확인하세요", "공식 정보 없음" 등 책임 회피 문장 (gaps에만 보관, 본문·FAQ 금지)
- 시로코 동일 문구 복붙 (각 시설 실제 풍경·특징으로 차별화 필수)
- 실제 성격이 아닌 곳에 "로맨틱" 강제

## 시로코 예시 분석
- intro: "저녁 한 번은 조금 특별하게" (매력) → "르부아 골든돔 아래 야외 테라스, 도시 불빛, 지중해 요리" (구체적 특징) → "연인 기념일·부모님 여행" (동행) → "식사 자체를 일정으로, 여유 있게, 야경 보며" (경험)
- reasons[2]: "이런 여행에는 잘 맞고, 이런 날에는 고민해보세요" — tradeoff를 결정 도움 맥락에 배치
- FAQ: 구체적 질문에 공식 근거로 답변, "예약할 때 당일 확인" 등 실용적 조언

## editorialReview 스키마 (시설별 제출 필수)
{
  "appeal": "이 시설만의 구체적 매력 (풍경·공간·서비스)",
  "companions": "실제로 잘 맞는 동행 유형",
  "experience": "추천 시간대·체류 방식·기대 경험",
  "tradeoff": "잘 맞는 경우 vs 고민해볼 경우",
  "factEvidence": ["공식 근거 URL 목록"],
  "pass": true/false (시로코 기준 전달력 충족 여부)
}

## 언어별 요구
- 11개 locale 모두 현지어로 같은 매력이 느껴져야 함
- 직역 금지, 자연스러운 여행 소개 문장
- 한국어 본문을 타언어 경로에 그대로 복제 금지
- 각 언어 본문 준비 시 shared component를 locale props로 사용
