# 제주항공(7C) 태국 직항 노선 안내

> 확인 기준일: 2026-10-13. 아래 본문은 공식 원문에서 확인된 사실만으로 작성했습니다. 미확인 항목은 '미확인'으로 표시합니다. 시각은 모두 현지시간(한국=KST, 태국=ICT)입니다.

## 운항 노선 3쌍

### 1. 인천(ICN) ↔ 방콕 수완나품(BKK) — 7C2503 / 7C2504

- **7C2503 (인천 → 방콕)**: 20:05 출발 → 익일 00:10 도착, 매일 운항(월~일)
- **7C2504 (방콕 → 인천)**: 01:10 출발 → 08:55 도착, 매일 운항(월~일)
- 운항 기간: 2026-10-01 ~ 2026-10-24 (제주항공 공식 운항표 Oct 1 rev7)
- 7C2503의 block time은 365분. 7C2504의 block time은 345분 (2026-10-13 제주항공 공식 당일 UI, airport local 명문 01:10→08:55 — 독립 확정. Oct Rev7 PDF의 reverse block 보류 근거와 분리 기록).
- "+1" 표기 주의: 7C2504의 "01:10+1 → 08:55+1"에서 +1은 인천 출발편(7C2503) 출발일 기준입니다. 복편 도착일에 +1을 붙이는 추론은 하지 마세요.

### 2. 인천(ICN) ↔ 치앙마이(CNX) — 7C2515 / 7C2516

- **7C2515 (인천 → 치앙마이)**: 18:10 출발 → 22:00 도착 (block 350분, 시차반영 정합)
- **7C2516 (치앙마이 → 인천)**: 23:00 출발 → 06:30 도착 (block 330분, 시차반영 정합). UI에 +1 표기가 없어 도착일/offset은 미확정 — 다음날 추론 금지.
- 확인 근거: 2026-10-13 제주항공 공식 UI 직접 실측분
- 요일 패턴과 공식 운항기간(종료일)은 미확인입니다. 위 날짜는 UI 실측일입니다.

### 3. 부산 김해(PUS) ↔ 방콕 수완나품(BKK) — 7C2551 / 7C2552

- **7C2551 (부산 → 방콕)**: 20:00 출발 → 23:50 도착 (block 350분, 시차반영 정합)
- **7C2552 (방콕 → 부산)**: 00:50 출발 → 08:30 도착 (block 340분, 시차반영 정합) — 2026-10-14 동일일 현지시각 (root 실제 조회). 이전 기록의 '08:30+1'은 잘못된 복제로 정정되었습니다.
- 확인 근거: 제주항공 공식 UI 직접 실측분
- 요일 패턴과 공식 운항기간(종료일)은 미확인입니다. 위 날짜는 UI 실측일입니다.

- 시즌 구분: 미확인
- 실제 비행 시간(airborne): 미확인
- 법인 실제 운항사·코드셰어 조건: 미확인 (마케팅 브랜드 7C는 확정, 법인 운항사 명문 없음 — 분리 기록)

## FAQ

**Q. 7C2503/2504는 매일 운항하나요?**
A. 네. 2026-10-01~10-24 기간 매일(월~일) 운항으로 공식 운항표에 명시되어 있습니다. 10-25 이후 일정은 미확인입니다.

**Q. 7C2504의 "01:10+1 → 08:55+1"은 무슨 뜻인가요?**
A. 인천 출발편(7C2503) 출발일을 기준으로 다음날이라는 뜻입니다. 방콕을 01:10에 출발해 인천에 08:55에 도착합니다(모두 현지시간).

**Q. 치앙마이·부산 노선(7C2515/2516/2551/2552)의 요일과 운항 기간을 알려주세요.**
A. 미확인입니다. 2026-10-13 제주항공 공식 UI에서 당일 스케줄로 확인된 분이며, 요일 패턴과 공식 운항기간(종료일)은 UI에 기재되어 있지 않았습니다.

**Q. 7C2552의 도착일은 언제인가요?**
A. 2026-10-14 동일일 08:30 도착입니다 (방콕 00:50 출발, 모두 현지시간). 이전에 표기된 '08:30+1'은 잘못된 복제로 정정되었습니다.

**Q. 인천공항·수완나품공항 몇 터미널을 이용하나요?**
A. 미확인입니다. 공식 운항표·UI에 터미널이 기재되어 있지 않았습니다.

**Q. 수하물이 파손·분실됐을 때 어떻게 하나요?**
A. 제주항공 공식 수하물 배상 안내 페이지(위 URL 참조)에서 안내합니다. 수하물 수령 후 7일 이내, 예정수령일로부터 21일 이내에 서면·현장으로 신고하세요. PIR 서식·카운터 직통 연락처·확인서 발급 절차는 미확인이니 해당 페이지에서 직접 확인하세요.

**Q. 7C2503/2504의 10월 24일 이후 스케줄은요?**
A. 미확인입니다. 공식 운항표(Oct 1 rev7)의 유효기간은 2026-10-24까지이며, 이후 일정은 공식 확인되지 않았습니다.
