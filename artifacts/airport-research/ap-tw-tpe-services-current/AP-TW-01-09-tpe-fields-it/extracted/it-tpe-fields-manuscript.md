# IT (타이거에어 타이완) × 타오위안(TPE) — 공항 이용 안내

## 체크인·발권 카운터
- 타오위안 공항의 IT 체크인 카운터 번호는 공식 채널에서 확인되지 않았습니다.
- 제3자 자료들은 제1터미널 이용을 안내하지만, 공식 확인이 아니라 미검증입니다.
- 카운터 위치는 시즌별로 바뀔 수 있으니 해당 항공사에서 확인 바랍니다.

## 공항·시내 사무실
- IT TPE 공항·시내 사무실 정보는 공식 확인되지 않았습니다.
- tigerairtw.com 공식 페이지 접근이 불가했습니다.

## 수하물 (파손·지연)
- IT TPE 수하물 접수처·전화·신고 기한은 공식 확인되지 않았습니다.
- 항공사 공식 채널에 직접 문의해 주세요.

## 지연·결항 확인서
- IT 확인서 발급 경로는 공식 확인되지 않았습니다.
- 항공사 공식 채널에 직접 문의해 주세요.

## 보험청구 증빙
- Fubon(富邦) 快捷 정액형은 항공사 지연증명이 필요 없어요. 여권/통장 사본과 실제 탑승권을 준비하고, 결항이면 대체편 증빙을 챙기세요.

## 자주 묻는 질문
**Q. 체크인 카운터 번호를 미리 알 수 있나요?**
A. 공식 채널에서 IT TPE 카운터 번호는 아직 확인되지 않았습니다. 카운터 위치는 시즌별로 바뀔 수 있으니 출발 전 항공사에서 확인해 주세요.

**Q. 수하물 문제나 지연 확인서는 어디에 문의하나요?**
A. 공식 페이지 접근이 어려우니 항공사 공식 채널에 직접 문의해 주세요.
