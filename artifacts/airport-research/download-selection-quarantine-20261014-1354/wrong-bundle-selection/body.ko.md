# CAAT 민원 포털 — 로그인 전 이용 순서 (공개 초기 화면 실측 범위)

- 관찰일: 2026-10-13 (브라우저 실측, 입력·가입·제출 없음)
- 범위: 로그인 전 공개 화면에서 실제로 보인 것만. 로그인 뒤 영역은 미검증(F-CMP-07)으로 분리.
- 금액·면제 조건은 현행 25조문 정본을 그대로 유지하며 여기에서 반복하지 않습니다.

## 로그인 전에 보이는 것

complaint.caat.or.th에 접속하면 별도 안내 페이지 없이 **CAAT Smart Platform 로그인 화면**(auth-itt.caat.or.th)으로 바로 이동합니다. 게스트(비로그인) 접수 경로는 없습니다.

로그인 화면에서 직접 확인된 것:
- 헤더 언어 토글로 **태국어·영어 전환** 가능
- 로그인 방식은 **이메일/사용자명 + 비밀번호** 1종 (OTP·여권번호 입력란 없음)
- 영어 화면 문구: "Log In" / "Email / User Name *" / "Password *" / "Remember me" / "Sign In" / "Or" / "Forgot password?" / "Don't have an account?" + "Sign Up"
- 소셜 로그인 3종 (파란색 'A' 아이콘, 'ThaiD', Google 'G')
- 지원팀 이메일 **asc@caat.co.th** 표시
- 회원가입 화면(입력 없이 관찰): Nationality(기본값 Thailand), ID Card Number, Title(기본값 Mr.), 성명, Email, Phone Number, Password(8~20자, 대·소문자·숫자/특수문자 각 1개 이상), 약관·개인정보·처리목적 동의 체크박스, Register 버튼
- 공식 게이트웨이(portal.caat.or.th/webportal/)의 '민원 접수' 타일을 눌러도 결국 로그인 화면으로 돌아옵니다

## 네 가지 채널 구분 (혼동 금지)

민원을 넣기 전에, 아래 네 가지는 서로 다른 창구입니다:

1. **현행 규정 (CAB Regulation No. 101)** — 권리의 근거. 지연·결항·탑승거부 시 돌봄·보상·환불의 조건을 정한 법규 자체입니다. 금액·면제 조건은 25조문 정본 기준.
2. **항공사 서면 신고** — 보상·환불 청구의 첫 단계. Art 18의 환불 신청서 등으로 **항공사에 먼저** 신청합니다. CAAT 포털이 아니라 항공사 창구입니다.
3. **보험청구** — 여행자보험을 통한 청구. 항공사도 CAAT도 아닌, 가입한 보험사의 별도 절차입니다. (본 인계 범위에서는 절차 미확인 — gap 유지)
4. **기관민원 (CAAT)** — 항공사가 법규를 위반했다고 판단될 때, 관련 증거와 함께 CAAT Complaint Management System에 신고하는 것 (Art 23). 로그인 필수, 증거 첨부. CAAT 영어 안내페이지도 "법정 권리를 받지 못했다면 https://complaint.caat.or.th 에 신고하라"고 안내합니다.

즉, 돈을 달라는 청구는 항공사에 먼저, 법규 위반 신고는 CAAT에. 보험은 또 별도입니다.

## FAQ

**Q. CAAT 민원 포털은 로그인 없이 이용할 수 있나요?**
A. 없습니다. 2026-10-13 실측 기준, complaint.caat.or.th 접속 시 CAAT Smart Platform 로그인 화면(auth-itt.caat.or.th)으로 리디렉션되며 게스트 접수 경로는 확인되지 않았습니다. 로그인은 이메일/사용자명 + 비밀번호 방식이며, 소셜 로그인 3종과 회원가입(Sign Up) 경로가 같은 화면에 있습니다. 로그인 뒤의 민원 양식 항목·처리 기한·추적 방법은 공개 화면에서 확인되지 않아 미검증으로 둡니다.
