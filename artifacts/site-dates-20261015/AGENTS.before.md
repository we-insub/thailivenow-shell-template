# ThaiLiveNow 작업 필수 규칙

## 모든 페이지 SEO 필수 규칙 (2026-10-14 사용자 확정)

모든 페이지를 새로 만들거나 수정하기 **전에 반드시 `docs/page-seo-rules.md` 전체를 읽고 적용한다.** 허브·상세·모든 언어/국가 페이지에 동일하게 적용하며 기존 페이지도 예외가 아니다.

- 중심 검색 의도와 실제 본문을 맞춰 고유 제목·설명을 작성한다. 미확인 키워드·조건·요금·서비스를 추가하지 않는다.
- 공통 메타 생성은 `src/lib/page-seo.mjs`, 자동 검사는 `scripts/audit-seo.mjs`를 사용한다. 개별 템플릿에서 충돌하는 중복 SEO 태그를 추가하지 않는다.
- `npm run build`의 SEO 검사를 통과해야 완료한다. 별도 출력 폴더로 Astro만 빌드했다면 해당 폴더에 감사 스크립트를 실행한다. 오류를 무시하거나 검사를 끄지 않는다.
- 자동 검사는 의미 검수를 대신하지 않는다. 제목·본문·대상 국가·언어·FAQ·근거를 직접 읽고 검토하며 경고 판단을 기록한다.
- 한국어 작성/수정은 `docs/natural-korean-copy.md`와 `docs/sirocco-user-full-reference-20261014.txt` 전체도 반드시 읽고 분석·재작성·사실 대조·시로코 비교·재검수한다.
- 로컬 검증 결과와 미완료 범위를 구분해서 보고하며 색인/상위노출은 보장하지 않는다. 운영 배포는 사용자 승인 범위에서만 수행한다.

## 모든 상세페이지는 시로코 기준

사용자 확정 지시(2026-10-14): 모든 새 상세페이지와 기존 상세페이지 수정에는 `docs/detail-template-rules.md`의 **모든 상세페이지 필수 기준 — 시로코**를 반드시 적용한다. 작업 시작 전 해당 문서를 읽는다. 과거 개별 템플릿·목차·임시 홀딩 기록과 충돌하면 최신 사용자 확정 절이 우선한다.

- 기준 소스: `src/components/RooftopDetail.astro`, `src/data/rooftops.json`의 시로코.
- 소개·핵심 지도/이용 안내를 앞에 배치하고 목차 없이 자연스러운 본문·기본정보·이용 순서·FAQ·관련 링크·출처로 구성한다.
- 자연스러운 말투, 충분한 여백, 모바일 표/카드 가독성, 핵심 조건 볼드를 필수 적용한다.
- 기존 데이터·상세 URL·공식 근거·예외를 보존하고 미확인 정보는 만들지 않는다.
- 모든 지원 언어에 적용하며 국가별 항공사/노선/연락처/보험 데이터를 섞지 않는다.
- 공항 시설 작업은 `docs/airport-facilities-implementation-20261014.md`도 읽는다. 자료조사는 사용자 지시대로 Muse가 수행하고 Codex는 회수·검수·구현한다.
- PC·모바일 및 변경 기능을 검증한 뒤 완료를 보고한다. 운영배포는 사용자 승인이 있는 범위에서만 실행한다.

## 상세페이지 출처 하단 공통 규칙 (2026-10-14 사용자 확정)

모든 상세페이지의 긴 참고 출처 목록은 기본 닫힘 상태의 접기·펼치기로 묶는다. 네이티브 details/summary를 우선 사용하고 제목은 해당 언어의 ‘공식 출처 보기 · N개’로 표시한다. 내부에는 간결한 출처명·실제 링크를 작은 글씨로 표시한다. 출처 확인일·최근 배포일은 접힌 영역 밖에서 항상 표시한다. 기존 날짜 산정 정책은 바꾸지 않는다. 지도·사진 저작권/라이선스 표시는 해당 지도·사진 옆에 계속 노출하며 접지 않는다. 중요한 적용조건·예외는 본문에 유지한다. 문단별 출처 번호로 접힌 출처에 이동하는 페이지는 이동 시 해당 details를 열어 근거를 볼 수 있게 한다. PC·모바일 및 키보드 접기·펼치기 동작을 확인한다.

## 본문 출처 번호 제거 (2026-10-14 사용자 확정)
모든 상세페이지 본문에 [1], [5], [6] 형태의 번호 출처 링크를 표시하지 않는다. 공식 근거 데이터와 하단 접기·펼치기 출처 목록은 보존한다. 기존 번호 참조 이동 기능은 본문에 새로 노출하지 않는다.

## 기존 한국어 원고와 사용자 제공 자료의 작업 범위 (2026-10-14 사용자 확정)

- 기존 페이지의 본문 사실·시간·요금·조건·예외·출처는 검증된 기준 자료로 받아들인다. 문장·구성·제목·메타 유지보수 요청을 공식 자료 재조사로 확대하지 않는다.
- 사용자가 새 페이지를 위해 검증된 내용으로 제공한 자료도 같은 기준으로 사용한다. 작성 전에 page-seo-rules.md와 natural-korean-copy.md, 시로코 전체 원문 및 detail-template-rules.md를 읽고 적용한다.
- 사실의 의미와 수치·적용 범위·예외·출처를 그대로 보존하면서 구체적인 행동과 자연스러운 한국어로 다시 쓴다. 제목·설명·H1·FAQ·구조화 데이터는 실제 본문과 맞춘다.
- 사용자가 별도로 사실 확인이나 자료조사를 요청한 경우에만 해당 범위를 조사한다. 자료 내부의 모순은 임의로 조건을 선택하거나 바꾸지 말고 별도로 기록한다. 새 사실을 창작하지 않는다.
- 검증은 원고 전후의 사실·수치·조건·출처 보존, 한국어 문장·구성, 메타 정합성, PC·모바일·링크·기능 및 빌드를 대상으로 한다. 운영 배포 범위는 최신 사용자 지시를 따른다.
