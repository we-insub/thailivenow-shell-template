# 코사무이 국제공항 (CAM-317)

수랏타니 코사무이의 코사무이 국제공항(Koh Samui Airport)을 비추는 웹캠으로, webcamtaxi에 등록된 카메라이에요. 인계 감사에서는 'webcamtaxi Offline 표기'로 제외 판정을 받았어요.

## 자주 묻는 질문

**어디서 볼 수 있나요?**
인계 URL인 webcamtaxi 사이트는 현재 접속이 되지만, 카메라 개별 페이지 주소가 없어서 해당 카메라를 바로 찾을 수는 없어요.

**지금도 방송 중인가요?**
인계 감사에서 'webcamtaxi Offline 표기'로 제외된 상태예요. 현재 재생 여부는 다시 확인하지 않았어요.

**이용 요금이 있나요?**
인계 기록에 따르면 무료로 볼 수 있고, 로그인은 필요 없어요.

**영상을 가져다 써도 되나요?**
영상 재사용 조건은 아직 확인되지 않았어요. 인계 기록도 '약관 미확인, 외부 링크만'으로 남겨져 있어요.

**카메라 위치는 어디인가요?**
코사무이 국제공항으로 안내되어 있지만, 정확한 좌표는 공개되어 있지 않아요. 제외 항목이라 좌표 추적은 진행하지 않았어요.

## 확인 상태 안내

- 재생: 인계 감사에서 'webcamtaxi Offline 표기'로 제외 판정. 현재 재생 상태는 텍스트로 확인되지 않아요.
- 운영자: '미확인 (중개: webcamtaxi)'으로 기록되어 있어요. 원천 운영자는 확인되지 않았어요.
- 좌표: 공식 좌표가 공개되어 있지 않아요. 제외 항목이라 추가 추적은 하지 않았어요.
