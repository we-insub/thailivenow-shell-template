# 스카이라인 반얀트리 라마이베이 — 코사무이 라마이 만 라이브캠

코사무이 라마이 베이의 파노라마 전망을 실시간으로 보여주는 해변 라이브캠이에요. SkylineWebcams 중개 페이지를 통해 무료로 시청할 수 있고, 로그인이 필요 없어요. Skyline 페이지에 따르면 카메라가 바라보는 곳은 라마이 만(Lamai Bay) 일대예요.

카메라의 명칭은 'Banyan Tree Samui'예요. 리조트 운영자인 Banyan Tree Hotels and Resorts의 공식 사이트에도 리조트 라이브캠(Resort Live Cam) 페이지가 마련되어 있어요 — 반얀트리 사무이를 내려다보는 자사의 실시간 카메라라고 안내하고 있어요. 두 페이지 모두 2026-10-13에 직접 열람으로 확인했어요.

재생 상태는 2026-10-12에 NATIONWIDE 담당이 실제 재생을 직접 확인했어요(Live 뱃지·수면 조명 반사 변화 확인). 2026-10-13 당일의 실시간 재생 여부는 재검증이 금지된 지시상 미확인 상태이므로, 시청 전 페이지에서 직접 확인해 보세요.

위치는 OSM 실객체 대조로 반얀트리 사무이 리조트 시설 좌표(9.4728522, 100.0693285)를 확보했어요. Skyline 공식 페이지에는 숫자 좌표가 게재되어 있지 않아요. 리조트 안의 카메라 정확한 설치 위치(루프탑인지 해변 쪽인지 등)는 공개되어 있지 않아요.

## 자주 묻는 질문

**이 카메라는 어디서 볼 수 있나요?**
SkylineWebcams의 공식 카메라 페이지(https://www.skylinewebcams.com/en/webcam/thailand/surat-thani/ko-samui/lamai-banyan-tree-samui.html)에서 시청해요. SkylineWebcams는 중개 사이트예요. 리조트 운영자의 공식 라이브캠 페이지(https://www.banyantree.com/thailand/samui/resort-live-cam)도 있어요.

**시청에 요금이나 로그인이 필요한가요?**
무료로 볼 수 있고 로그인은 필요 없어요(인계 자료 회수 기준).

**카메라 영상은 어디까지 재사용할 수 있나요?**
SkylineWebcams 공식 약관(VisioRay Srl 운영)에 따르면 콘텐츠의 독점 소유권은 VisioRay에 있고, 허용되는 이용은 열람과 사이트 내 공유 링크를 통한 공유뿐이에요. 무단 복제·다운로드·추출·배포는 금지되어 있어요. 재사용 승인을 받으려면 info@visioray.com으로 이메일을 보내야 해요. 라이브 영상 임베드는 웹캠 호스트만 가능하고, 일반 사이트는 5분마다 갱신되는 포토그램(photogram)을 'Embed' 버튼에서 얻는 HTML 코드로만 삽입할 수 있어요. (CAM-004 작업에서 2026-10-13에 약관·FAQ를 공식 확인한 기록을 회수했어요.)

**카메라가 정확히 어디에 있나요?**
페이지 명칭상 반얀트리 사무이(Banyan Tree Samui) 관련 카메라예요. 다만 Skyline 페이지 본문에는 카메라의 설치 주체가 명시되어 있지 않고(제목에만 표기), 리조트 내 정확한 설치 위치도 공개되어 있지 않아요. 시설 좌표는 OSM 실객체 대조(9.4728522, 100.0693285)로 확보했고, 공식 페이지에 숫자 좌표는 게재되어 있지 않아요.

**지금도 실제로 방송 중인가요?**
2026-10-12에 NATIONWIDE 담당이 실제 재생을 직접 확인했어요. 2026-10-13 당일의 실시간 재생 여부는 재검증이 금지된 지시상 미확인 상태이므로, 시청 전 페이지에서 직접 확인해 보세요.
