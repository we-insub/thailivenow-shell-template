- 홈페이지에 Routes and Fares(노선·요금), Station and Places(역·장소 검색), 운행 시간·배차, 분실물 안내 메뉴가 있음
- 고객센터 0 2617 6000 (매일 06:00–24:00)
- 1회권 이용법(2차 출처): 자판기에서 목적지 선택 → 1회권 발권 → 입장 시 탭, 퇴장 시 투입구에 삽입
- Rabbit 카드 등록제(2차 출처): 구매 시 외국인 여권 필요. 1회권은 등록 불필요.

### MRT 블루·퍼플라인 (BEM 공식 https://metro.bemplc.co.th 기준)
- 운행 시간: 월–일 06:00–24:00, 평시 배차 7분 이내, 첨두(07:00–09:00·16:30–19:30) 4분 이내
- 결제: EMV Contactless 카드(Visa·Mastercard·UnionPay·Mangmoom)를 개찰구에 직접 탭
- 문의: 0-2624-5200

### 공통 이용 규칙 (2차 출처 — 공식 FAQ 대조 필요)
- 열차 내·승강장 음식물 섭취 금지, 러시 아워(07:00–09:00·17:00–19:00) 혼잡
- 90cm 미만 어린이 무료 (2차 출처)

## 4. SRT 도시간기차 (공식 근거)

- 공식 예매: D-Ticket — 웹사이트 www.dticket.railway.co.th, 모바일 앱, 전국 SRT 역 창구, 콜센터 1690 (24시간)
- 사전 예매 기간: CNR 특급 8개 왕복(방콕↔치앙마이·우본랏차타니·농카이·핫야이)은 90일 전부터, 그 외 열차는 30일 전부터, 보통·통근 열차는 당일 역에서만 구매 (2차 출처)
- 열차 등급: Ordinary / Rapid / Special Express (2차 출처)
- 결제: 신용·체크카드, 복지카드 (2차 출처)
- 대기 명단 기능: 2024-05부터 등록 사용자에게 매진 시 대기 접수 (2차 출처)
- SRT 공식 사이트(https://www.srt.or.th) 접속 실패 → 공식 페이지 직접 확인은 미완료
