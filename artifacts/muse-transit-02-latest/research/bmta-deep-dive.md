## 1. 확보 항목

### 1-1. 에어컨 vs 일반버스 요금 체계 [공식인용]

BMTA 공지(공지일 2019-04-10, 시행일 2019-04-22)를 thaipost.net이 전문 인용. 근거 결의: 중앙육상교통통제위원회 10/2561 (2018-12-14).
- 일반버스(크림-빨강): 8바트 전 구간
- 에어컨버스(크림-파랑): 12–20바트 (거리별)
- 에어컨버스(유로II 주황): 13–25바트 (거리별)
- 에어컨버스(신형 파랑): 첫 4km 15바트, 4–16km 20바트, 16km 이상 25바트
- 고속도로 이용 시: +2바트/인/회
- 심야 운행(23:00–05:00): +1.50바트/인/회
- 근거 URL: https://www.thaipost.net/main/detail/33363
- 상태: BMTA 공지 원문(페이스북 게시물)의 직접 URL은 미확보. 언론이 공지 전문을 인용한 형태.

보조 확인 [2차]: th.wikipedia.org/wiki/องค์การขนส่งมวลชนกรุงเทพ 의 요금표 — 크림-파랑 에어컨의 거리별 단계(4km당 12/14/16/18/20바트), 고속도로 +2바트, 복지카드 -4바트. 위키라 최종 근거로는 부적합.

### 1-2. 차장 결제 방식 (승차→결제) [공식인용]

"ไทยช่วยไทย พลัส"(Thai Chuay Thai Plus) 정부 프로그램: 2026-06-01~2026-09-30, 매일 06:00–23:00.
- BMTA 버스 전 차량에서 차장(พนักงานเก็บค่าโดยสาร)에게 เป๋าตัง(Pao Tang) 앱 G Wallet으로 QR 스캔 결제
- 정부 60% 지원 + 본인 40% 부담
- BMTA 이사장(นายกิตติกานต์ จอมดวง จารุวรพลกุล) 공식 발언을 Manager Online·Siam Rath·Kom Chad Luek이 인용
- 근거 URL: https://today.line.me/th/v3/article/vXap5Jj (Manager Online), https://today.line.me/th/v3/article/j7KBewg (Kom Chad Luek, 정부 부대변인 발표 포함)
- 상태: 언론 보도이나 BMTA 이사장·정부 부대변인의 공식 발언 인용. 정부 프로그램 공식 페이지는 미확보.

### 1-3. BMTA BUS 앱·핫라인 1348 [공식]

태국 정부 포털 공식 안내 페이지에서 확인 (기존 조사에서 확보, 재확인).
- 실시간 버스 위치, 출발·도착 입력 시 노선·정류장 추천, 태국어·영어, 무료
- 근거 URL: https://thailand.go.th/issue-focus-detail/--bmta-bus------?hl=en

### 1-4. 시내버스 vs 도시간버스 구분 [공식인용·2차]

- BMTA: 방콕수도권(방콕·논타부리·빠툼타니·사뭇쁘라깐·사뭇사콘·나콘빠톰) 시내버스 운행 [2차: en.wikipedia.org/wiki/Bangkok_Mass_Transit_Authority]
- 도시간버스(หมวด 2: 방콕–지방, หมวด 3: 지방–지방)는 DLT 관할로 별도 요금 조정 (2026-09-11 중앙육상교통통제위원회 결의, 2026-09-15 시행, 3사탕/km 인상) [공식인용: https://today.line.me/th/v3/article/oqREgLp]
- 즉, BMTA(시내)와 DLT/Transport Co.(도시간)는 관할·요금 체계가 분리되어 있음.

### 1-5. 참고: EV 버스 전환 [공식인용]

- 교통부 장관 발언(2025-09-26, BMTA 창립 49주년): BMTA 보유 2,883대 중 에어컨 1,363대·일반 1,520대. 2026년 9월부터 EV 1,520대 단계적 도입, 일반버스 요금 8바트 유지 방안 검토 [공식인용: https://www.matichon.co.th/economy/news_5385109]
- Thai Smile Bus(민영 EV): 15–20–25바트 거리별, HOP 카드 일 40바트 상한 [2차: https://www.lifestyleasia.com/bk-th/whats-on/news-whats-on/ev-bus-bangkok-fare-comparison/]

## 2. 미확보 항목 (시도한 URL과 실패 이유)

### 2-1. BMTA 공식 요금표 원문 URL — 미확보
- 시도: https://www.bmta.co.th/ (공식 홈페이지) → 텍스트 추출 시 환영 문구("ยินดีต้อนรับสู่ องค์การขนส่งมวลชนกรุงเทพ")만 나옴. JS 렌더링 사이트라 텍스트 도구로 내용 확인 불가.
- 시도: https://www.bmta.co.th/bus-lines/61 (검색에서 반환된 공식 URL) → 방문자 수·핫라인 1348만 표시되고 본문 없음. 같은 원인(JS 렌더링).
- 필요: 라이브 브라우저에서 태국어 메뉴(요금 안내)를 직접 열어 확인할 것.

### 2-2. BMTA 공식 Facebook(ขสมก. พร้อมบวก) 요금 게시물 원문 — 미확보
- 시도: 웹 검색 "facebook.com ขสมก พร้อมบวก ประกาศ อัตราค่าโดยสาร" → BMTA 공식 페이지의 특정 게시물 URL을 반환하지 않음 (방콕시 공식 페이지의 철도 관련 게시물만 반환).
- facebook-cli는 본인이 관리하는 페이지가 아닌 공개 페이지의 게시물 목록을 제공하지 않아, 게시물 URL 없이는 조회 불가.
- 필요: 라이브 브라우저에서 BMTA 공식 페이지를 열어 요금 공지 게시물을 찾을 것.

### 2-3. 승차→요금확인→결제→하차요청→하차 순서의 공식 안내 — 미확보
- 시도: bmta.co.th / mot.go.th / dlt.go.th / thailand.go.th 에서 "วิธีขึ้นรถเมล์"(버스 타는 법), "คู่มือผู้โดยสาร"(승객 안내서), PDF·FAQ 검색 → 공식 절차 안내 페이지·PDF를 찾지 못함.
- 차장에게 행선지를 말하고 요금을 내는 방식, 하차벨 등은 2차 출처(여행 블로그·Medium 등)에만 존재하여 공식 근거로 사용 불가.
- 필요: 라이브 브라우저에서 bmta.co.th 태국어 FAQ/이용안내 메뉴 확인.

### 2-4. mot.go.th / dlt.go.th의 BMTA 요금 고시 원문 — 미확보
- 시도: site:mot.go.th / site:dlt.go.th 로 "ประกาศ ขสมก อัตราค่าโดยสาร" 검색 → 반환된 것은 철도 데이터 카탈로그(datagov.mot.go.th)와 도시간버스(หมวด 2/3) 요금 조정 보도뿐. BMTA 시내버스 요금 고시 원문 없음.
- 참고: 시내버스 요금은 중앙육상교통통제위원회 결의 → BMTA 공지 형태로 발표되는 구조 (2019년 사례).

### 2-5. TAT 공식 방콕 버스 이용 안내 — 미확보
- 시도: "tourismthailand.org Bangkok bus BMTA guide" 검색 → TAT 공식 버스 가이드를 반환하지 않음 (언론·블로그만 반환).
- TAT 뉴스룸(tatnews.org)은 도시간버스 운행 재개 보도 등 여행 맥락 자료만 있음.

## 3. 집계

- 확보: 5건 (1-1 요금 체계[공식인용], 1-2 차장 QR 결제[공식인용], 1-3 앱·핫라인[공식], 1-4 시내/도시간 구분[공식인용·2차], 1-5 EV 전환 참고[공식인용])
- 미확보: 5건 (2-1 요금표 원문 URL, 2-2 FB 요금 게시물 원문, 2-3 승차·하차 절차 공식 안내, 2-4 MOT/DLT 고시 원문, 2-5 TAT 버스 가이드)
- 공통 실패 원인: bmta.co.th의 JS 렌더링으로 텍스트 추출 불가 → 라이브 브라우저 위임 필요. 공식 Facebook 게시물은 검색으로 특정 URL 확보 불가 → 라이브 브라우저에서 직접 탐색 필요.
- 추정 없음. 위 "공식인용" 항목은 언론이 공식 공지·발언을 인용한 것으로, 원문 URL 확보 시 "공식"으로 승격 가능.
