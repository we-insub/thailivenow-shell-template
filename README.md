# ThaiLiveNow shell template

태국·방콕 여행 사이트를 만들 때 사용할 수 있는 한국어 기본 UI 쉘입니다. JapanLiveNow 코드나 운영 데이터와 연결하지 않은 독립 템플릿입니다.

## 포함된 화면

- 반응형 헤더와 한국어 기본 메뉴
- 지도 자리표시자, 검색 입력, 지역 선택
- 목적지·맛집·교통·카메라·쿠폰·항공편 섹션
- 카드, 빈 상태, 모바일 레이아웃, 푸터

## 제외된 항목

지도·날씨·카메라·항공·검색 API, 실제 태국 콘텐츠, 제휴 링크와 추적값은 포함하지 않았습니다.

## 실행

```bash
npm install
npm run dev
```

운영에 사용하기 전 태국 공식 출처와 콘텐츠를 확인하고 빈 상태를 실제 데이터로 교체하세요.
