# Git handoff 검증 기록

검증일: 2026-10-17. 대상: `main`, `origin` = https://github.com/we-insub/thailivenow-shell-template.git . 시작 HEAD는 `0da8d5eb`이며 fetch 후 origin/main과 차이 0/0을 확인했다. 이번 작업은 개발·규칙 인계 정리이며 운영 배포·색인 제출을 수행하지 않는다.

## 포함·제외 및 기존 작업 보존

- 기존 추적된 src, public의 공개 데이터·이미지, Functions, 설정, package/lock, 날짜·릴리스 코드와 테스트를 유지했다. 필요한 미추적 제작 규칙·시로코 전체 기준 원문·시장 결정·헤더/내부 링크 규칙·참조 시범 데이터와 감사 도구를 선별해 추가했다.
- 시작 시 AGENTS.md의 기존 변경은 사용자 확정 제작 지시였으며 이 작업 목적에 필요한 규칙으로 보존·포함했다. 공항 개인 조사 대화/회수 기록은 원본을 로컬에 보존하고 제작 지시만 `airport-facilities-rules.md`에 이식했다. 무관한 조사 자료·작업 로그·QA·미추적 원고·데이터는 stage하지 않았다.
- `.env` 및 변형, 인증서·개인키, Wrangler 세션·상태, node_modules, dist, .astro, artifacts, 캐시·임시·로그·Python 바이트코드를 제외했다. `.env.example`은 변수명과 용도만 포함한다.
- `public/data/site-dates.json`은 추적된 날짜 observations/baseline과 명시된 릴리스 정보로 재생성하는 로컬 산출물로 제외했다. 기존 로컬 파일은 삭제하지 않았다. Git에서 이미 추적된 제외 패턴 파일은 별도로 `git ls-files -ci --exclude-standard`로 확인했으며 0건이다. 추적 해제가 필요한 실제 비밀 파일은 발견하지 않았다.
- 전체 Git index의 파일 내용에 개인키 헤더·대표 토큰 형식·긴 credential 할당 패턴을 값 노출 없이 검사해 후보 0건을 확인했다. 이는 전체 Git 이력과 외부 서비스의 비밀 유효성을 보증하는 검사가 아니다. 이력 재작성·강제 푸시는 하지 않았다.

## 필수 문서·참조 추적

`handoff-required-files.json`의 63개 파일은 존재와 Git 추적을 검사한다. AGENTS → SEO·날짜 3문서·상세 기준·한국어 전체 원문·시로코 정본, 서비스 목적/검색 우선순위, 언어/시장, 헤더/내부 링크 및 그 실제 컴포넌트·데이터·스크립트·테스트가 포함된다. 개인 스킬·개인 메모리에만 있는 필수 규칙은 발견하지 않았고 저장소 문서를 정본으로 명시했다.

문서 내 파일 경로와 상대 링크를 대조했다. RuntimeDate 축약 경로는 실제 소스 경로로 수정했다. 개인 프로젝트/백업에 의존하던 헤더 이식 기록 대신 추적된 실제 디자인 소스로 연결했다. 다음 참조는 개발 필수 파일과 구분한다.

## 커밋·원격 상태

- 정리 소스 커밋: `478ac0f8f8254c3af298251b1c7baae98b66caa5`.
- 푸시 대상: `origin/main`. git push 성공 후 git ls-remote의 refs/heads/main이 위 SHA와 정확히 일치하는 것을 확인했다.
- 전체 빌드/런타임 검증 snapshot은 임시 detached 커밋 `4b6fbc48914e4a6cde0d18edcf30a80ed217fbd6`이다. 정리 소스 커밋과의 차이는 이 검증 기록 및 필수 파일 목록 두 문서뿐이며 실행 소스·설정·lockfile·테스트는 동일하다. 실제 푸시한 정리 커밋으로 새 detached checkout을 만들어 필수 63파일 검사도 재확인했다.
- 이 원격 확인 기록은 후속 문서 커밋으로 저장한다. 그 문서 커밋 SHA는 자기 참조를 피하기 위해 파일 안에 고정하지 않으며 `git log -1 --format=%H -- docs/GIT-HANDOFF-VERIFICATION.md`로 조회한다. 최종 원격 일치 여부는 작업 종료 시 별도로 확인한다.
- 파일 저장·이 컴퓨터의 깨끗한 checkout 검증·원격 푸시를 확인했다. 다른 컴퓨터의 실제 실행과 운영 반영은 확인하지 않았다.

## 별도 준비

Git, 지정 Node/npm, npm 및 Wrangler 다운로드 인터넷 접근이 필요하다. 기본 로컬 실행에는 API 키가 필요 없다. 외부 지도 타일·카메라·공식 링크의 가용성은 해당 제공자에 의존한다. Muse 신규 조사·비공개 ZIP은 별도 자료와 접근권한이 필요하다. 배포에는 Cloudflare 권한·사용자 승인·명시된 배포 날짜/커밋이 필요하고, 부분 배포에는 검증된 운영 기준 세트가 별도로 필요하다. clone/pull만으로 외부 계정·운영 기준·조사 자료·다른 컴퓨터의 설치까지 자동 복제된다고 주장하지 않는다.
