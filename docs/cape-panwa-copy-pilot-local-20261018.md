# 케이프 판와 한국어 시범 수정

## 승인 범위와 목적

사용자는 카메라 29곳 전체 검수를 요청한 뒤 ‘일단 케이프판와 하나 먼저’로 순서를 정했다. 이번 작업은 한국어 `phuket-cape-panwa` 한 곳의 목록 미리보기와 상세를 먼저 수정한다. 나머지 28개 원고·FAQ와 다른 언어 상세는 유지한다. 카메라 메뉴에서 풍경을 보고 영상을 재생하는 목적이며, 현장 방문·수영·시설 입장 가이드를 새로 작성하지 않는다. 운영 배포·푸시·커밋 없음.

## 기준과 문장 검토

기존 AGENTS.md, 상세 템플릿, natural-korean-copy.md, 사용자 시로코 전체 원문, SEO·연결·날짜 규칙을 같은 작업 흐름에서 읽고 적용했다. 시로코의 조사 경위 대신 실제 풍경·행동을 설명하는 기준으로 다시 썼다. 현장에 다녀온 듯한 허위 경험담은 만들지 않았다.

- 이전: ‘만과 바다를 안내해요’, ‘NĀMA는 이 화면을 공개하는 제공자의 이름이에요’ → 카메라에서 보이는 만·바다·수평선을 먼저 설명한다. 영상 제공자는 영상 아래 출처 링크로 표시한다.
- 이전: ‘이 풍경을 이렇게 살펴보세요’, 촬영 시각을 확인하라는 반복 안내 → 소제목을 빼고 여행 전 바다 풍경을 감상하는 짧은 문단으로 연결한다.
- 이전: 버튼을 어디서 누르는지, 큰 사진이 실시간인지, 지도 핀이 출입구인지 묻는 FAQ → 세 질문 삭제. ‘케이프 판와는 어떤 곳인가요?’ 하나만 남긴다. FAQ를 정해진 개수로 채우지 않는다.
- 이전: ‘이어서 살펴보세요’ → 소제목 없이 실제 목적지를 설명하는 ‘태국 라이브캠 전체 보기’ 링크.
- 다른 해변이 담긴 지역 참고사진은 이 시범 목록 카드와 상세에서 표시하지 않는다. 상세는 실제 기존 유튜브 플레이어를 중심으로 구성한다. 목록은 라이브캠을 뜻하는 재생 아이콘을 사용하고 사진으로 오인시키지 않는다. 원본 사진 데이터·라이선스·출처를 삭제하지 않는다.

## 화면·사실·연결

제목·미리보기·소개·메타 설명·Article/FAQ 스키마를 시범 원고와 맞춘다. 순서는 소개 → 풍경 → 실제 라이브캠·유튜브 원본·영상 제공자 → 케이프 판와 위치·날씨 → 장소 질문 하나 → 전체 목록 → 접힌 출처와 날짜다.

기존 NĀMA 제공 페이지, YouTube ID, 위치 근거와 참고 좌표, 날짜 기록을 유지한다. 지도 핀이 정확한 설치 지점·출입구가 아니라는 설명은 지도 옆에 한 번만 둔다. 영상을 현재 재생 확인한 기록이나 새 시설·교통 사실을 추가하지 않는다.

목록의 사진 영역·제목·라이브캠 링크에서 동일한 한국어 상세로 이동하고, 상세에서 한국어 목록으로 돌아간다. 같은 지역의 시설을 임의로 추가 연결하지 않는다. canonical·공개 URL·언어 대응을 바꾸지 않는다. 실제 내용 수정일은 운영 시간대 Asia/Bangkok의 2026-10-17이며, 일본 클라이언트 날짜는 2026-10-18이다. 자료 확인일·운영 배포일을 수정일로 덮어쓰지 않는다.

### 실제 원고 비교

시로코 소개는 장소·무엇을 누리는지·누구와 어떤 때 좋은지·그곳에서 보낼 시간을 연결한다. 케이프 판와의 기존 시범은 ‘바다를 볼 수 있어요’ 한 문장으로 끝냈다. 재작업에서는 푸껫 남동쪽·Tang Khen Bay·만과 바다·수평선·하늘이라는 보존 사실을 두 문단으로 연결하고, 여행 전 현지 풍경이 궁금한 사람과 잠깐 바다를 보며 쉬고 싶은 사람의 이용 장면을 제안했다. 방문 경험·혼잡도·수영 가능·시설 입장조건·교통편은 창작하지 않았다.

시로코의 경험 본문은 구체적인 풍경을 행동과 연결한다. 이번에는 만과 수평선이 함께 보이는 화면을 설명하고, 맑거나 구름 낀 하늘에 따라 보이는 풍경이 달라지는 감상 문단을 분리했다. 장소 소개를 같은 말로 여러 번 복제하지 않는다. 날씨에 대한 문장은 조건부 일반 관찰과 이용 제안이며, 오늘 맑다거나 특정 파도 상태라고 주장하지 않는다.

시로코의 기본정보는 실제 제공하는 항목을 분명하게 보여준다. 케이프 판와는 촬영 지역·영상 제공자·실제 원본 영상 경로를 정의 목록으로 정리했다. 영상 재생·전체화면은 실제 플레이어 행동으로 설명한다. 위치는 기존 [98.408, 7.807] 참고 좌표로 실제 지도에 표시하고, 설치 지점·방문 출입구로 승격하지 않는다. 지도는 기존 resilient-map과 MapLibre·동일 지도 스타일을 사용하며 라이선스/지도 출처 표시는 지도에 유지한다.

FAQ는 장소 질문과 밤에 화면이 어두운 이유 두 개만 작성했다. 야간 화면은 기존 Muse CAM-002 원본 sourceFields의 ‘해변(야간)’에 관찰 근거가 있고, 답변은 현지가 밤이면 바다가 어둡게 보일 수 있다는 설명이다. 24시간 무중단 방송이나 오늘의 재생 상태를 보증하지 않는다. 버튼을 어디서 누르는지·참고사진인지·핀으로 방문하는지의 억지 FAQ를 다시 만들지 않았다.

원고·레이아웃 수정은 케이프 판와 하나다. 날씨 모듈은 이 페이지에서만 지정하는 제목을 지원하며 다른 페이지의 기본 제목과 동작은 유지한다. 다른 28개와 운영 배포는 범위 밖이다. 이전 1개 FAQ 시범은 이번 재작업으로 대체되며 새 결과는 별도 `artifacts/cape-panwa-rework`에 보존한다.

### 재작업 최종 로컬 확인

최종 출력은 `artifacts/cape-panwa-rework/dist-final`. 테스트 40개, 전체 1,822페이지 빌드, SEO 오류/중복 제목/중복 설명 0개, 날짜 감사 3,168바인딩, 디자인 issues 없음, 실제 Pages 런타임 11개 시장 홈·데이터·미리보기 보호 검사 통과. 전체 긴 제목 등 경고 134개는 기존 다른 경로이며 시범 제목·본문·메타 설명을 별도로 읽고 대조했다.

본문 내용·링크·사진·영상과 원고 데이터 대조에서 나머지 한국어 상세 28개와 다른 시장의 케이프 판와 10개는 유지됐다. 카메라 API도 기존과 동일하다. 시범의 FAQ 스키마 2개는 실제 질문·답과 일치한다.

실제 브라우저 CSS 너비 320·390·1422px에서 가로 넘침·본문 넘침 없음. 소개 두 문단의 간격 약 18px, 지도 폭이 본문 안에 유지되는 것, 기존 YouTube ID 일치를 확인했다. 지도 타일 로드 후 data-map-ready=true, 위치 표식과 지도 출처 표시, 브라우저 오류 로그 없음 확인. 출처 전용 summary의 Enter 펼침/접힘 확인. 초기 지도 로딩 상태를 성공으로 계산하지 않았다.

수정된 목록 문장과 단일 시범 제목·링크를 PC/390px에서 확인하고 목록↔상세 왕복했다. 최종 전체 캡처는 `detail-desktop.png`, `detail-mobile.png`, 목록은 `preview.png`, `preview-mobile.png`. 측정 및 소스 보존 기록은 `responsive.json`, `html-audit.json`, 실제 읽은 원문 버전은 `read-source-versions.json`이다. 이 기록이나 빌드 통과가 사람의 문체 검수를 대신하지 않으며 사용자 최종 수용을 뜻하지 않는다. 현재 로컬 8788은 이 최종 출력으로 실행 중이다. 커밋·푸시·운영 배포는 하지 않았다.
