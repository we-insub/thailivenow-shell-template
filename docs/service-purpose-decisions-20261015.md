# ThaiLiveNow 서비스·페이지 역할 확정 사항

2026-10-15 사용자 직접 확정. 이 문서는 확정 사항만 기록하며 페이지 수정·다국어 제작·배포·색인 제출을 승인하는 문서가 아니다.

## 서비스 목적과 대상

- 서비스 목적: 태국 여행을 준비하고 현지에서 필요한 정보를 찾는 종합 여행 안내.
- 중심 이용자: 관광 여행자.
- 기존 확정된 최우선 목표 키워드 ‘태국 여행’을 유지한다. 관련 기존 기록은 `docs/service-keyword-priority.json`이다.
- 지도·카메라 등 특정 기능 하나를 서비스 전체의 목적으로 정하지 않는다.

## 내비게이션과 페이지 역할

- 기존 내비게이션을 유지한다. 현재 지도 홈과 각 메뉴의 위치를 재배치하지 않는다.
- 공항 메뉴의 명칭·역할은 ‘공항·항공편’으로 정리한다. 이번에는 기준만 기록하며 실제 메뉴 문구는 수정하지 않는다.
- 쿠폰은 여행 전반의 혜택 안내를 목표로 한다. 사용자는 추후 JapanLiveNow처럼 변경·업데이트할 예정이라고 밝혔다. 구체적인 구성과 구현 시점은 이번 기록에서 확정하지 않는다.

## 다국어와 시장별 조건

- 다국어도 같은 페이지 역할을 목표로 한다.
- 확인된 태국 사실은 유지하고 시장별 적용 조건은 구분한다.
- 각 시장의 자연스러운 검색 표현과 문장으로 작성한다.
- 기존에 확정된 지원 언어·시장과 국가별 자료 분리 기준을 유지한다. 같은 페이지 역할이라는 이유로 다른 시장의 여권·항공사·노선·연락처·보험 조건을 복제하지 않는다.

## 향후 적용과 이번 작업 범위

### 운영 안내·문의처 추가 확정

- 사용자 확정 공식 문의 이메일: `hello@thailivenow.com`.
- 서비스 소개, 문의·오류 신고·권리자 요청, 출처 및 이용 안내, 이용약관·제휴 안내, 개인정보 처리방침과 하단 연결 방식은 JapanLiveNow와 같은 구성을 기준으로 준비한다.
- 공식 이메일은 문의 페이지와 필요한 운영·약관·개인정보 안내에 일관되게 사용한다. 링크를 구현할 때는 `mailto:hello@thailivenow.com`을 사용한다.
- 안내 내용은 ThaiLiveNow의 확정된 종합 여행 안내 목적과 실제 운영에 맞춘다. JapanLiveNow의 운영자 명칭·제휴업체·데이터 이용조건·보관기간·개인정보 처리 사실을 그대로 복제하지 않는다.
- 이메일 주소 확정은 메일 수신 동작이나 메일 제공자 확인을 의미하지 않는다. 메일 제공자와 처리·보관 기준 등 미확정 사항은 실제 개인정보 안내 제작 전에 필요한 범위만 확인한다.
- 이번 추가 요청은 기준·이메일 기록으로 반영하며, 기존 기록만 요청한 범위를 유지한다. 페이지 생성·수정·통계 기능 변경·운영 배포는 수행하지 않는다.

- 향후 승인된 작업에서 위 기준을 제목·H1·설명·본문·내부 링크에 일관되게 적용한다.
- 이미 확정된 내용은 재사용하고 반복해서 묻지 않는다. 새로운 부분이나 모호하거나 충돌하는 부분만 사용자에게 짧게 묶어서 질문한다.
- 기존 검증·공개 규칙은 유지한다.
- 이번 요청은 작업 MD에 확정 사항을 기록하는 것만 포함한다. 페이지·메뉴·SEO·다국어 콘텐츠 수정, 운영 배포, 색인 제출은 수행하지 않는다.
