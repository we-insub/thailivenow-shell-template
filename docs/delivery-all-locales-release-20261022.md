# 배달 안내 11개 언어 CSS·소제목 배포

2026-10-22 (사용자 시간대) 승인: 배달 안내의 11개 언어 CSS를 확인·수정하고 소제목을 자연스러운 각 언어로 변경한다. 로컬 검수 후 운영 배포·Git main 푸시, 실제 운영 검수를 진행한다. 범위는 /{locale}/food-delivery/ 및 연결된 4개 앱 안내이며 다른 작업은 섞지 않는다.

## 보존과 수정

- 한국어 공통 TransportGuidePage에서 일반 목록의 padding-left:4px!important가 단계 배지 공간을 덮는 충돌을 수정했다. food-delivery-guide 클래스를 허브와 grabfood/line-man/shopeefood/robinhood에 적용하고 국내선과 동일한 PC 68px·모바일 58px 간격을 확보한다.
- 다른 10개 언어는 LocalizedDeliveryGuide에 이미 전용 패딩이 있어 그 CSS는 유지하고 실제 브라우저로 간격과 가로 넘침을 확인한다.
- 한국어 소제목은 사용자가 정한 ‘배달음식 호텔로 주문하는 방법’. 영어권은 ‘How to get food delivered to your hotel’. 각 언어 원고의 호텔 주문 맥락을 읽고 현지 표현으로 변경한다.
- 한국어 제목만 수정한 앞 단계에서 sourceFingerprints 갱신이 누락되어 전체 원본 일치 검사 1건이 실패한 것을 발견했다. 이번 11개 언어 검수에서는 기존 검증 본문의 유일한 변경이 order.title임을 대조한 뒤 원본 대조값을 갱신했다. 검사를 삭제하거나 기준을 완화하지 않았으며 142개 테스트가 통과했다.
- 본문·수치·요금·조건·FAQ·사진·출처·URL·내부 연결·메타·색인 정책·실제 자료 확인일은 보존한다. 관련 상위↔앱별 상세 링크와 각 언어 정본을 유지하고 신규 라우트를 만들지 않는다.
