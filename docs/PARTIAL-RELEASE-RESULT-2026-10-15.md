# 부분 배포 구현·검증 결과

## 구현과 공통 규칙

실제 Vite dependency graph로 영향 라우트를 선택하고 성공 운영 결과물의 전체 트리와 합친다. git archive로 지정 커밋만 추출하므로 다른 작업의 미커밋·미추적 파일을 제외한다. AGENTS.md, 날짜 계약·페이지 명세·운영 문서에 PARTIAL-RELEASE.md를 연결했다. npm run build의 기존 전체 모드는 보존한다. 부분 모드도 전체 테스트, 합친 1,821개 페이지 SEO/날짜 감사, 실제 Pages 로컬 서버 검사를 유지한다. CSS·JS 참조 6,804개도 확인한다.

## 로컬 검증

- 전체 테스트 29개 통과: 원래 21개와 부분 배포 8개.
- 최종 전체 기준 생성 62.932초. 1,821개 HTML, SEO 오류 0, 제목/설명 중복 0, 기존 경고 134개 유지.
- 한 페이지 변경 시험의 초기 실행: 1개 HTML 재생성, 1,820개 해시 보존, 전체 사이트 총 1,821개 유지. 검사·로컬 서버를 포함한 40.369초. 페이지 렌더링 단계는 약 17초에서 5~8초로 줄었다.
- 기준/그래프 변조, 미확인 의존성, 공통 변경, 재사용 자산 누락, 삭제 자산 참조를 검사한다. 새/알 수 없는 소스 및 빌드/Functions/패키지 변경은 전체 모드로 전환한다. 실패한 후보는 기준이 되지 않는다.
- 지원 11개 언어의 로컬 HTML과 날짜 스냅샷, JSON/API/통계 자산/robots/sitemap 및 preview noindex 확인. PC 1440×900, 모바일 390×844의 대표 페이지는 H1 1개, 가로 넘침 없음.
- 카메라 29개와 기존 페이지 날짜 기록 1,356개를 보존했다. 자료 확인·장애·링크 기록·실제 수정일을 배포일로 바꾸지 않았다.

## Git·운영

최종 구현 코드 84d156e9260f30652a146cb598102022f05678ed를 GitHub main/codex/site-dates에 푸시했다. 격리한 동일 소스와 정식 Wrangler 4.151.0으로 https://2c9601cb.thai-live-now.pages.dev → https://thailivenow.com 운영 배포했다. 실제 운영 언어별 대표 응답·주요 정적 자산·공통 날짜 JSON·미리보기 noindex 18개 확인 후 재사용 기준으로 승격했다. 변경 자산은 날짜 JSON 1개, 나머지 1,931개는 Cloudflare 재사용이었다.

이 기록을 포함한 커밋으로 실제 부분 모드 운영 배포를 실행하고, 최종 한 페이지 시험·미커밋 파일 제외·운영 PC/모바일 및 새 배포 ID를 확인한 뒤 완료 기록을 추가한다. 시험용 원고 커밋은 GitHub 푸시와 운영 배포에서 제외한다.

검증 중 구형 전역 Wrangler 선택과 fetch의 Host 처리 차이는 고정 버전 및 실제 HTTP Host 요청으로 수정했다. 저장 공간 부족은 이번 작업이 만든 임시 의존성/컴파일/런타임 사본만 정리해 해결했다. 업로드와 로컬 서버는 이제 감사한 결과물을 직접 사용하며 불필요한 추가 복사를 하지 않는다. QA와 다른 작업 변경은 보존했다.
