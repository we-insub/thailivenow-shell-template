# 음식 섹션 다국어 현지화 — 작업 브리프 (2026-10-23)

## 사용자 확정

- `/ko/food/` 전체(허브 1 + 전통음식·길거리 음식·과일 허브·과일 가격 + 도시 6 + 요리 22 + 과일 16 = 49쪽)를 나머지 10개 언어·시장 `ms`, `zh-cn`, `zh-tw`, `en`, `en-us`, `en-gb`, `en-in`, `ru`, `ja`, `es`에 같은 구조로 만든다.
- 사진·템플릿·CSS·레이아웃은 한국판 그대로 쓴다. 바뀌는 것은 글, 제목, 메타 설명, H1, FAQ, 구조화 데이터, alt·캡션, 내부 링크 문구다.
- 영어는 시장별(`en-us`, `en-gb`, `en-in`)로 따로 쓰고 `en`은 국가를 가리지 않는 공통 영어로 둔다. 번역이 아니라 해당 시장의 검색 표현으로 다시 쓴다.
- 배포·푸시·색인 제출은 이 작업에 포함하지 않는다.

## 구조

- 구조 데이터(ID·월·가격 숫자·사진 파일·출처 URL)는 `src/data/food.json`에 그대로 두고, 언어별 표시 글은 `src/data/food-localized/<언어>.json` 한 파일에 둔다.
- `src/data/food-localized/ko.json`이 기준 구조다. 모든 키·배열 길이·`{placeholder}`·`**굵게**`·`|`(줄바꿈 표시)를 같게 유지해야 한다. `node scripts/validate-food-pack.mjs <언어>`가 구조를 검사한다. 문장 품질은 검사하지 못하므로 사람이 읽고 확인한다.
- `meta`는 페이지 경로 → 메타 설명이다. 검수 뒤 `src/data/meta-descriptions/<언어>.json`에 합친다.

## 작성 규칙

1. 한국어 문장을 옮기지 않고, 그 시장 독자가 같은 질문을 검색할 때 쓰는 표현으로 다시 쓴다. 한국 독자를 전제로 한 비유(김치 맛 비교 등)는 해당 시장에서 자연스러운 비유로 바꾸거나 뺀다.
2. 숫자·월·가격·단위·조건·예외·고유명사와 사실의 범위는 바꾸지 않는다. 본문에 없는 가격·시간·효능·할랄/채식 여부·환율 환산을 새로 만들지 않는다.
3. 제목·H1·소개·FAQ에는 그 페이지를 찾는 사람이 검색할 말(대상의 이름 + 알고 싶은 것)을 자연스럽게 넣는다. 검색어 나열·반복 금지.
4. 메타 설명은 `AGENTS.md`의 "메타 설명 기준 — 2026-10-23"을 읽고 따른다. 공백·문장부호 포함 150~199자, 자연스러운 완전한 문장, 큰따옴표·이모지 금지, 핵심 검색어를 앞부분(한·중·일은 앞 60자, 그 밖은 앞 120자)에, 페이지마다 달라야 하고, 본문에 없는 사실 금지.
5. `**…**`는 굵게, `|`는 H1의 줄바꿈이다. 기준 파일과 같은 위치·개수로 둔다. HTML 태그는 쓰지 않는다.
6. `emphasis` 배열은 같은 요리의 소개·맛·재료·이야기·팁·단계 문장 안에 실제로 들어 있는 짧은 구절이어야 한다.
7. 요리·과일 이름은 그 시장에서 알아보는 이름을 쓴다(필요하면 현지 표기에 일반 표기를 병기). 영어·태국어 표기는 `food.json`에 이미 있다.
8. 출처 라벨은 기관명을 그 언어의 통용 표기로 쓴다. URL은 건드리지 않는다.
9. `fruits.<id>.regional`은 한국판에 값이 있을 때만 문자열이고 없으면 `null`이다. `availability`와 `seasonLabel`은 화면 표시용이다.

## 시장별 참고

| 언어 | 방향 |
| --- | --- |
| `ms` | 말레이시아 말레이어(인도네시아어 어휘 금지). 말레이시아 여행자가 쓰는 표현. 할랄·채식은 한국판 본문이 말하는 범위(이름만으로 판단할 수 없다)까지만 쓴다. |
| `zh-cn` | 간체, 중국 대륙 용어. |
| `zh-tw` | 번체, 대만 용어. 간체를 변환하지 말고 따로 쓴다. |
| `ja` | です・ます体. タイ料理・屋台・フルーツ 등 일본어 검색 표현. |
| `ru` | Русский, 자연스러운 여행 안내 문체. |
| `es` | 스페인 스페인어(es-ES). |
| `en` | 국가를 가리지 않는 공통 영어. 특정 시장의 관용구·철자 차이를 피한다. |
| `en-us` | 미국 철자·어휘. |
| `en-gb` | 영국 철자·어휘. |
| `en-in` | 인도 영어 독자. 인도 독자에게 중요한 식재료 조건(채식·동물성 조미료)을 한국판 본문에 있는 정보 범위에서 앞세운다. |

## 연결·날짜·저자 (구현 쪽에서 처리)

- 글·해설 저자 줄, author/publisher 연결, 날짜 표시, hreflang, canonical, sitemap, 내부 링크는 템플릿·공통 정책이 처리한다. 팩에 넣지 않는다.
- 같은 시장끼리만 내부 링크한다(`/en-gb/food/…` 안에서는 `/en-gb/…`로만 연결).
