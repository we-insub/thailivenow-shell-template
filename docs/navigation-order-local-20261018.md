# PC·모바일 내비게이션 순서 통일

사용자 요청에 따라 한국어 공통 헤더의 기존 PC 순서를 모바일에도 적용했다.

지도 → 태국 여행 → 음식 → 교통 → 태국 공항 → 카메라 → 저장 → 배달 → 루프탑 → 해변 → 쿠폰 → 지연·결항.

`DetailHeader.astro`의 공항 우선 배치와 `site-adapter.css`의 모바일 전용 재정렬을 제거했다. 기존 배열·메뉴 이름·주소·활성 표시·모바일 가로 스크롤을 유지했다. 콘텐츠·정본 URL·언어·공개 상태·날짜 데이터는 변경하지 않았다.

실제 브라우저 1280px PC와 390px 모바일에서 12개 링크 순서 및 계산된 order=0을 대조했다. 페이지 가로 넘침 없음. 증빙은 `artifacts/navigation-order-20261018/`. 전체 테스트 51개 통과. 로컬 반영이며 푸시·운영 배포는 하지 않았다.
