# 공항 시내 이동 선택 문구·버튼과 지도 복구

대상: 한국어 `/ko/transport/airports/suvarnabhumi-to-bangkok/`의 이동 방법 비교 기능과 공항철도 지도. 사용자 스크린샷의 문구·버튼 너비·빈 지도·지도 버튼 무반응을 수정한다. 기존 요금·시간·승차 위치·노선 형상·확인일·정본·관련 페이지 연결과 시로코/SEO/날짜 기준을 유지한다.

- 소개를 ‘숙소가 있는 지역을 고르고, 공항에서 출발하는 시각을 입력해보세요.’ 다음 줄에 ‘타는 곳과 환승 경로, 비용 기준을 함께 비교할 수 있어요.’가 나오도록 나눴다.
- 시간 항목은 ‘공항에서 출발할 예상 시각’으로 고쳤다. 태국 현지 시각이며 항공편 도착시각이 아닌 입국심사·짐 찾기 후 숙소로 출발할 시각이라는 설명을 유지했다.
- 비교/다시 고르기 버튼은 2열 동일 비율 그리드로 수정했다. PC 너비 497px씩·높이 58.4px씩, 모바일 390px에서 너비 157px씩·높이 90.8px씩 확인했다. 모바일 긴 버튼 문구의 줄바꿈에도 높이가 같다.
- 지도 미표시는 개발 서버가 오래된 Vite 사전 번들 URL을 가리켜 지도 라이브러리 요청이 504로 실패했기 때문이다. 실제 HTTP 504와 디스크 메타데이터의 번들 누락을 확인한 뒤 기존 4321 개발 서버만 재시작했다. 새 서버는 같은 localhost:4321 주소를 사용한다. 지도 코드·좌표·공식 노선 형상을 임의로 바꾸지 않았다.
- 정상화 후 지도 canvas·배경 지도·역 핀·철도 노선과 data-map-ready=true 확인. 전체 구간/마카산/파야타이 버튼을 실제 클릭해 선택 상태와 지도 핀의 화면 위치가 각각 바뀌는지 확인했다. 전체 빌드 뒤 새로고침해도 동작한다. Pages 로컬 4338의 빌드에서도 canvas와 파야타이 버튼을 별도로 확인했다.
- 아속·17:00으로 비교 시 결과 표시와 기존 52바트 안내, 초기화 시 결과 숨김·시간 값 비움 확인. 모바일 가로 넘침 없음, 소개 br 줄바꿈과 시간 라벨 확인.
- 전체 테스트 51개 통과, 전체 빌드 1,825페이지·SEO 오류 0개·기존 경고 134개, 날짜 테스트 9개·감사 3,204 bindings 오류 없음. Pages 로컬 런타임 passed=true, 전체 디자인 감사 1,825페이지 issues=[].
- 증거: `artifacts/airport-transfer-ui-20261018/`의 map-buttons.json, mobile-checks.json과 PC/모바일 화면 PNG. 소스 변경은 AirportTransferChooser.astro의 문구와 버튼 CSS다. 운영 배포·푸시·색인 제출은 하지 않았다.
