# 신규 페이지 날짜 명세

페이지 생성·유지보수 전에 [SITE-DATES.md](./SITE-DATES.md)를 반드시 읽는다. 기존 SEO·상세 템플릿·한국어 규칙도 계속 적용한다.

1. 각 날짜의 의미를 배포·자료 확인·링크 점검·실제 수정·촬영/관측/행사로 구분한다.
2. 공통 표시는 RuntimeDate로 연결한다. 카메라 ID 또는 대표 페이지 경로를 명시한다.
3. 실제 확인 자료의 날짜를 observations에 등록한다. 정확한 시각이 없으면 null과 원문 기록을 유지한다.
4. JSON-LD는 실제 수정일 정책을 따르며 배포일 상속을 만들지 않는다.
5. 전체 기존 관문과 날짜 감사, 실제 Pages 런타임, 서버 응답 및 클라이언트 이후 값을 검증한다.

공통 날짜 표식이 없는 새 날짜 표현을 만들 때는 prepare·audit·테스트에 해당 형식을 추가한다. 제목·canonical·hreflang·사이트맵·제휴 추적·색인 정책은 날짜 작업으로 변경하지 않는다.
