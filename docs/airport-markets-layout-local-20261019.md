## 화면·연결

한국어 승인 흐름인 상황 1~4 → 공항 기록 보관 → CAAT 지원·보상/보험 구분 → 네 개의 항공사·공항 도구 → FAQ/닫힌 출처를 새 공통 AirportAssistanceHub로 적용한다. 한국어 원문을 각 시장의 한국 항공사·한국 보험사 자료로 번역 복제하지 않는다. 예를 들어 중국 본토에는 평안, 대만에는 푸본의 기존 해당 국가 보험 안내가 연결된다. CAAT는 태국 출발 정기 국제선이라는 공통 조건을 유지하고 다른 국가 출발편에 그대로 적용하지 않는다.

국가별 중심 URL은 `/{locale}/airport-assistance/`다. 하위 화면은 각 시장마다 아래 네 경로로 분리한다.

1. `airlines/`: 시장에 실제 등록된 운항 항공사를 현지 이름·영문명·검증된 코드·편명으로 검색한다. 상황 카드의 `?issue=delay|cancellation|missing|damage`는 동일 검색 화면에 첫 행동을 표시하고 항공편/수하물 관련 안내 링크를 골라준다. 새 query 색인 문서나 가상의 상황 상세 URL을 만들지 않는다. 원문별 정확한 신고 기한·증빙은 해당 항공사 상세와 기존 가이드에서 읽는다.
2. `departure-airports/`: 이 시장의 노선 끝점인 출발공항만 선택하고 해당 공항의 기존 서비스만 출력한다. 체크인/짐 부치기 → 발권·사무실 → 수하물·유실물 → 예약·일반 상담을 구분한다. 전화가 현장 직통인지 원격 상담인지는 원문 설명을 보존한다.
3. `airports/`: 기존 BKK·DMK·HKT·CNX 같은 언어 실제 공항 상세로 연결한다. 없는 지도·번역·새 시설 사실은 생성하지 않는다.
4. `flights/`: 허브에서 펼쳐져 있던 기존 노선·편명·날짜·상태·기간·운항시간·공항쌍과 연구 범위 자료를 이동한다. 공개 노선 수와 개별 URL은 그대로다. 현재 운항 상태와 과거/단일 날짜 관찰을 혼동하지 않는다. 특히 미국 자료의 BTS 1~7월 전수/현재 운항사/겨울 전체 미확인 경계는 보존한다.

허브의 네 도구는 현지 항공사, 공통 English 검색, 해당 국가 출발공항, 태국 공항이다. 노선 탐색은 별도 링크로 진입한다. 9개 국가 허브에서 신규 36개 하위 URL로 연결하고, 항공사·공항·노선·공항쌍 상세의 상단 복귀 링크와 breadcrumb는 실제 새 상위 화면을 따르게 했다. 국가별 안내에서 다른 시장으로 조용히 대체하지 않는다. English 공통 검색은 언어가 달라짐을 설명한다. 언어 선택에서도 en을 홈으로 보내던 공항 전용 예외를 제거해 실제 `/en/airport-assistance/`로 이동한다.
