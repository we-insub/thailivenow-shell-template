# 카메라 장소 미리보기·상세 한국어 정비 — 로컬 검수

## 사용자 요청과 범위

처음 태국을 알아보는 한국어 이용자가 카메라 이름만 보고도 어디를 보는지, 어떤 풍경인지, 실제 화면을 어디서 여는지 이해하도록 기존 카메라 29개의 미리보기와 연결 상세를 수정했다. 위치는 기존 카메라 메뉴(`/ko/directory/`), 지도와 저장·비교 화면이다. 카메라별 한국어 상세 29개가 이번 상세 작업의 범위이며 사이트의 모든 관광지·교통 상세를 다시 작성한 작업은 아니다. 운영 배포·푸시·커밋은 하지 않는다.

## 적용 규칙

작업 전 `AGENTS.md`, `docs/INTERNAL-LINKING-CONTRACT.md`, `docs/SITE-DATES.md`, `docs/page-generation-date-contract.md`, `docs/operations-site-dates.md`, `docs/page-seo-rules.md`, `docs/natural-korean-copy.md`, `docs/sirocco-user-full-reference-20261014.txt`, `docs/detail-template-rules.md`를 읽고 적용했다. 시로코 기준과 비교해 소개 → 사진·시청 버튼 → 장소 설명 → 기본정보·이용 순서 → 위치 → FAQ → 관련 링크 → 접힌 출처 순서로 구성했다. 목차와 본문 출처 번호를 추가하지 않았다.

## 기존 자료를 사용하는 방식

- `src/data/cameras.ts`의 기존 소개·촬영 지역·제공 URL·위치 근거와 `src/data/map.ts`의 지역 설명을 사용한다. 새로 작성한 문구와 입력 근거는 `src/data/camera-editorial-ko.json`에 ID별로 기록했다.
- 카메라 원본 데이터와 검증 기록, URL, YouTube ID, 좌표, 참고사진과 출처·저작권은 보존했다. 새 사실 조사나 현재 재생 확인으로 확대하지 않았다.
- 사진은 기존 지역 참고사진이다. 같은 지역의 다른 장소가 담길 수 있어 사진 옆에 명시하고 대체 텍스트도 지역 참고사진으로 표현했다. 새 카메라 캡처처럼 표시하지 않는다.
- 갱신 사진과 동영상의 시청 방법을 구분하고 과거 재생 확인 기록을 현재 생방송 보증으로 표현하지 않는다. 위치가 없는 항목에 좌표나 방문객 출입구를 만들지 않는다.
- 해변 정본 데이터(`src/data/beaches.json`)가 비어 있어 새 해변 상세·교통편·요금·영업시간·수영 가능 조건을 만들지 않았다. 이 부분은 방문 안내 자료가 추가로 필요한 범위다.
- 치앙마이 항목은 기존 원시 확인 문구와 미확인 재생 상태 간 불일치가 있어 현재 확인 완료로 승격하지 않고 미확인 상태를 따른다. 원시 기록은 변경하지 않는다.
- 중개 사이트를 원천 운영자 공식 사이트로 단정하지 않는다. 하단 출처 제목은 상세 공통 규칙을 따르고, 내부에서 중개 사이트와 원천 공식 홈페이지를 구분하도록 안내한다.

## 연결·SEO·날짜

목록의 사진·제목·장소·시청 안내가 실제 한국어 상세로 이어진다. 상세에서 상위 카메라 목록으로 돌아간다. 동일 해변으로 확인되는 파통, 라마이, 후아힌의 3쌍에만 상호 링크를 추가했다. 서로 다른 촬영 장비나 각도라는 보장은 하지 않는다. 같은 도시라는 이유만으로 다른 시설·일정을 연결하지 않는다.

한국어 상세의 제목·메타 설명·H1·본문·FAQ 스키마를 맞췄다. canonical·사이트맵·초기 HTML 내부 링크 대상을 검사했다. 한국어가 아닌 기존 290개 상세는 원래 템플릿을 그대로 유지한다.

실제 문구 수정일만 2026-10-17로 기록했다. 기존 카메라 자료 확인일·최근 성공 배포일과 구분하며 공통 RuntimeDate·Pages 서버 날짜를 사용한다. 이 로컬 수정으로 운영 배포일을 갱신하지 않는다.

## 2026-10-18 사용자 문구 피드백 반영 (Bangkok 수정일 2026-10-17)

앞선 검수에서 반복적인 내부 검증 문구를 본문에 남겼다. 사용자 피드백을 우선해 다음과 같이 수정했다. 이전 기록의 ‘확인 기록을 본문에 안내’하는 구성은 이 절로 대체한다.

- ‘어떤 곳을 보고 있나요?’ → ‘어떤 풍경을 볼 수 있나요?’
- 기본정보의 ‘이전 확인 기록’ 행 삭제. 원본 카메라 데이터·확인일은 보존하며 하단 자료 확인일도 유지한다. 비교 화면의 반복 확인 기록도 제거했다.
- ‘제공 사이트에서 보는 순서’ → 영상 종류에 맞는 H2. 기존 검증 라이브 영상은 ‘실시간 라이브캠 보는 방법’, 현재 재생 미검증 항목은 ‘카메라 영상 보는 방법’, 갱신 사진 3개는 ‘갱신 사진 보는 방법’. 사진을 동영상으로 표시하지 않는다.
- 유튜브 ID가 있는 6개는 ‘해당 영상은 유튜브 원본에서도 확인하실 수 있어요’와 실제 원본 영상 버튼을 제공한다. 기존 공식 제공 페이지는 출처에 보존한다. 유튜브가 아닌 나머지는 기존 제공 URL을 유지하며 유튜브 원본이라고 쓰지 않는다.
- 시청 순서는 두 단계로 줄였다. 플레이어 재생 또는 원본 링크를 여는 실제 행동을 알려주고 반복적인 기록·시각 확인 요구를 제거했다. FAQ도 같은 안내로 수정했으며 플레이어 위치가 FAQ보다 위이므로 FAQ에서는 ‘이 페이지의 플레이어’라고 쓴다.
- 시로코 원문과 비교: 조사 경위 대신 독자의 행동을 먼저 설명하고, ‘확인해주세요’의 반복을 줄이며, 질문에 직접 답한다. 전체 한국어 자연스러움을 자동 점수나 문자열 검사만으로 보장하지 않는다.

SEO/AEO/GEO 판단: 질문에 맞는 구체적인 소제목과 실제 답을 제공하는 편집 판단이다. ‘라이브캠·CCTV’ 키워드를 모두 넣어 검색량·순위·AI 인용이 높아진다고 주장하지 않는다. Google의 [AI features and your website](https://developers.google.com/search/docs/appearance/ai-features)는 기존 SEO 원칙·유용한 본문·화면과 구조화 데이터 일치를 강조하며 별도 특수 최적화를 요구하지 않는다. CCTV는 모든 촬영 화면의 공통 명칭으로 추가하지 않았다.
