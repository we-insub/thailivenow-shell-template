# 수완나폼 항공사별 체크인 카운터 안내 정리

## 사용자 확정 목적

대상은 한국어 `/ko/airport-assistance/airports/bkk/airlines/`다. 독자가 자신의 항공사·편명으로 체크인 위치와 수속 시간을 찾고 필요한 문의처를 구분하도록 작성한다. 검색·답변 엔진이 같은 질문과 답을 읽을 수 있도록 제목·소개·소제목·기본정보·FAQ·실제 연결을 맞춘다. 순위나 AI 인용 성과를 검증했다고 보고하지 않는다.

사용자는 뒤섞인 업무별 목록을 정렬하고, 에어프레미아의 Q5–10 같은 표기를 읽기 쉬운 문장으로 설명하며 대한항공처럼 편명을 함께 안내하도록 요청했다. 새로운 사실 조사나 다른 시장·공항의 재편은 이번 범위가 아니다.

## 변경

- 17개 원본 서비스 행을 업무별로 체크인 9개 → 발권·스카이패스 1개 → 공항 사무실 3개 → 수하물·분실물 3개 → 예약센터 1개 순서로 묶었다. 각 그룹은 한국어 항공사 이름순이다. 모르는 서비스 종류는 조용히 누락하지 않고 분류 오류로 검출한다.
- 체크인 카드는 항공사 → 위치/요일·좌석등급별 배정 → 시작·마감 또는 편명별 운영시간 → 이용 조건 → 연결된 한국행 출발편 → 연락처/상세/자료 확인일의 같은 구조를 사용한다. 없는 세부 구역·카운터·연락처는 만들거나 빈 행으로 표시하지 않는다.
- 에어프레미아 ‘화·수·목·토요일 Q5–10’은 ‘화·수·목·토요일: Q구역 5~10번 체크인 카운터(Q5–Q10)’로 표시한다. 금요일 W1–W6, 일요일 U1–U6도 같은 방식으로 설명한다. 월요일은 항공사에 먼저 문의하고 다른 요일도 당일 전광판으로 배정을 확인하도록 안내한다.
- 대한항공 체크인은 KE660/658/652/656 운영시간을 각각의 행으로 표시하고, KE656의 다음 날 01:35 마감과 태국 현지 시각을 유지한다. 발권 U24/U22/U21은 다른 업무 그룹에서 편명별로 나눈다.
- 다른 항공사의 K/N/M/U 구역, H6–H17/A3–A10 좌석등급 구분, 에어부산 부산행 BX726 S16–S19와 인천행 S12–S15도 풀어 쓴다. 아시아나 A380의 50분 전 마감 예외를 보존한다.
- 체크인 9개 항공사에는 기존 자료의 BKK 출발 노선만 연결한다. 에어프레미아는 YP602이며 도착편 YP601을 출발 카운터 안내로 붙이지 않는다. 다른 항공사·공항의 편명을 끌어오거나 확인된 기간 밖의 상시 운항을 만들지 않는다. 확인한 출발·도착일/기간을 함께 표시하고 당일 운항 조회와 구분한다.
- 에어프레미아의 전화는 기존 자료의 역할에 맞춰 ‘공항 안내 전화’로 표시한다. 같은 번호를 문단과 전화 링크에 두 번 쓰지 않는다. 모바일 탑승권 가능·키오스크 불가는 별도 기본정보 행으로 유지한다.
- 길게 펼쳐져 있던 노선 32개·공항쌍 3개·관련 대응 안내는 하단에서 주제별로 접어 찾도록 바꿨다. 실제 초기 HTML의 관련 링크와 원래 정본 주소를 보존한다. 공식 출처 30개도 기본 닫힘 상태이며 확인일은 밖에 표시한다.

## 한국어·SEO/AEO/GEO 및 내부 연결

시로코 전체 원문의 ‘어디서 무엇을 하는지 구체적으로 설명’, 조건·예외 유지, 질문에 먼저 답하기 기준을 적용했다. 본문의 Q구역/번호 설명, 요일별 표, 편명별 시간, FAQ는 실제 표시 자료와 일치한다. FAQ 5개를 같은 배열에서 화면과 한 FAQPage로 만든다. 메타 설명도 카운터 구역·번호·수속 시작·마감·편명별 안내라는 실제 본문에 맞춰 수정했다.

상위 태국 공항 메뉴, 공항 목록 복귀, 수완나폼 1~5 페이지네이션은 유지한다. 기존 항공사 상세 9곳에서 들어오는 카운터 링크의 목적지 URL도 유지한다. 각 카드에서 해당 항공사 상세와 실제 같은 항공사의 BKK 출발 노선으로 연결한다. 지도·흡연·기본 이용 안내와의 본문 연결을 유지했다. 범용 관계 엔진을 새로 구현하거나 색인 제출을 수행한 작업이 아니다.

원본 `public/data/airport-assistance.json`의 위치·시간·연락처·출처·확인일을 바꾸지 않고 표시용 세부 데이터를 추가했다. 확인일은 기존 2026-10-13, 실제 콘텐츠 수정일은 Asia/Bangkok 기준의 기존 이번 작업일 2026-10-17이며, 배포일을 현재 날짜로 바꾸지 않았다. 다른 작업의 소스·QA를 보존했다.

## 검증

- 전체 테스트 51개 통과. 업무 혼합/중복/누락 방지, 같은 항공사 BKK 출발편 연결, 요일·좌석등급·A380 예외·익일 마감 회귀 테스트 포함.
- 전체 빌드 1,825페이지, SEO 오류 0개·중복 제목/설명 0개, 기존 경고 134개. 날짜 테스트 9개 및 3,204개 bindings 감사 오류 없음. Pages 로컬 런타임 passed=true. 전체 디자인 감사 1,825페이지 issues=[].
- 초기 HTML에서 서비스 17행이 각각 한 번 표시되고 그룹 순서·전화/이메일·자료 확인일이 유지되는지 확인. 기존 노선 32개 링크 보존, 9개 체크인 카드의 편명은 같은 항공사의 BKK 출발인지 확인. 에어프레미아 전화는 카드 안에서 한 번만 표시. FAQ 5개와 화면 본문 일치 확인.
- 실제 사용자 URL localhost:4321과 Pages 로컬 4338에서 HTTP 200 및 5개 그룹/17개 서비스/풀어 쓴 Q구역 안내 확인.
- 실제 브라우저 PC와 모바일 390×844에서 업무 분류·항공사 정렬·요일별 행·가로 넘침 없음 확인. 대한항공 편명별 시간 화면, 접힌 노선 자료 키보드 Enter 동작(32개 링크 펼침/접힘), 태국 공항 메뉴 유지 확인.
- 증거는 `artifacts/bkk-counter-layout-20261018/`의 html-checks.json, mobile-checks.json과 에어프레미아 PC/모바일·대한항공 PC PNG다.

운영 배포·커밋·푸시·실제 수집·색인·상위 노출·AI 인용 측정은 수행하지 않았다.
