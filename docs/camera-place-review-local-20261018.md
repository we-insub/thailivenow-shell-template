## 사용자 확정 범위

케이프 판와 시범을 나머지 28개 미리보기·상세로 확대한다. 진행 중 사용자는 카메라 사용법보다 **카메라가 비추는 장소가 어떤 곳이고 여행에서 어떤 풍경을 만날 수 있는지** 먼저 설명하도록 정정했다. 케이프 판와도 이 최신 기준으로 재수정한다. 한국어 `/ko/`만 변경한다. 로컬 PC·모바일 확인 후 보여주며 커밋·푸시·운영 배포는 하지 않는다.

내비게이션은 기존 카메라 메뉴와 목록·지도·저장·비교를 유지한다. 실제 촬영 장소를 알고 여행 후보를 살펴보려는 한국어 이용자가 대상이다. 새 해변·시설·일정·번역을 공개하지 않는다. 기존 원본 데이터와 사용권 기록, 카메라 확인 이력은 유지한다.

## 문장 분석과 재작성

기존 28개는 지역명·제공자 설명, ‘카메라를 고르세요’, ‘현재 재생을 확인하세요’가 본문과 FAQ에 반복됐다. 사용자 최신 피드백을 반영해 장소 소개 → 구체적인 풍경 → 실제 화면 → 기본정보 → 위치가 있는 경우 지도·날씨 → 필요한 질문만 → 관련 링크·접힌 출처 순서로 정리했다. 시로코의 소개·경험·FAQ와 비교해 장소 특징과 여행 장면을 연결하고, 자료 확인 과정이나 모든 문장을 같은 권유로 끝내는 서술을 줄였다.

- 파통: 푸껫 해변 → 휘어진 만·모래사장·숙소와 쇼핑/야간 활동이 있는 지역 소개 → 15층 전망과 도시 파노라마의 촬영 대상 구분.
- 카론: 해변 남쪽의 영상 안내만 반복하던 문구 → 길게 이어지는 흰 모래와 주변 식당·상점, 카타 북쪽이라는 장소 특징.
- 카타: 지역의 카타 야이/카타 노이 소개와 해당 항목의 갱신 사진을 구분. 두 해변이 모두 카메라에 나온다고 쓰지 않는다.
- 라마이: 레스토랑 제공자 이름만 설명하던 본문 → 굽은 만과 코코넛 나무가 있는 해변 소개. 실제 화면 설명은 기존 모래사장·파도 범위로 유지한다.
- 케이프 판와: ‘잠깐 쉬어가세요’ 삭제. 푸껫 남동쪽 해안과 나마 앞 만을 소개하고 라이브캠은 실제 풍경을 보는 수단으로 배치한다.
- FAQ는 고정 4문항 생성 제거. 질문이 없는 곳에는 제목·카드·FAQPage 구조화 데이터를 모두 만들지 않는다. 본문과 동일한 질문/답 배열을 사용한다. 강제로 클릭 방법·큰 참고사진·지도 핀에 대한 질문을 채우지 않는다.

기존 검증 사실을 기본으로 사용한다. 사용자 진행 중 ‘실제 명소 소개’라는 내용 보강 지시에 따라 아래 1차 자료에서 지리·경관·지역 특징에 한해 보강했다. 요금·영업시간·교통·수영 안전·실제 현재 재생을 새로 조사한 작업으로 확대하지 않았다. 원문의 수영 권유·현재 안전·교통 소요시간·인기 순위는 추가하지 않았다.

## 사진·지도·연결

기존 사진 데이터와 저작권을 지우지 않는다. 한국어 미리보기에서는 촬영 대상과 다른 지역 참고사진을 대신 보여주지 않고 장소명이 있는 그래픽 표지를 사용한다. 한국어 상세는 기존 허용 플레이어 또는 실제 원본 링크로 연결한다. 다른 10개 시장의 사진/본문은 그대로 유지한다.

기존 center가 있는 12개만 실제 지도와 참고 위치 표식을 표시한다. 없는 곳에는 새 좌표·가짜 방문 입구를 만들지 않는다. 지도 라벨을 한글 장소명으로 바꾸고 설치 지점/출입구가 아니라는 설명은 지도 옆에 둔다. OSM 등 지도 출처는 지도에 유지한다.

상위 `/ko/directory/` 및 2쪽의 초기 HTML에서 상세로, 상세에서 `/ko/directory/`로 실제 링크를 출력한다. 지도 결과·선택 카드·저장·비교의 미리보기도 같은 원고를 사용한다. 파통 두 전망, 라마이 두 레스토랑 앞, 후아힌 두 전망만 기존 사실상 관계의 상호 링크를 유지한다. 다른 시설·도시·일정은 같은 지역이라는 이유로 추가하지 않는다. 자동 관계 엔진은 이번에 구현하지 않았으며 실제 HTML과 관계를 수동 대조한다.
