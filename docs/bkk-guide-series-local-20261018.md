# 수완나폼 한국어 공항안내 5개 페이지 구성

## 사용자 확정 범위

2026-10-18 한국시간 요청. 한국 여행자를 위한 한국어 `/ko/` 안내를 다음 순서로 분리한다. 태국 공항 내비게이션 → 공항 목록 → 수완나폼 안내라는 기존 발견 경로를 유지한다. 다른 세 공항과 외국어 페이지의 분리는 이번 범위가 아니다.

| 순서·ID | 대표 경로 | 주된 질문 |
| --- | --- | --- |

4번은 기존 시내 이동 상세의 대표 주소와 본문·교통 지도·조건을 재사용했다. 중복 시내 이동 상세를 추가하지 않았다. 각 페이지의 상단·하단에 순서가 같은 1~5 링크와 이전·다음 링크를 출력하고 현재 페이지를 aria-current로 표시한다. 이는 한 페이지 안의 목차가 아닌 별도 URL 간 탐색이다.

## 연관 페이지 계약 적용

`INTERNAL-LINKING-CONTRACT.md`, page-seo-rules, 상세 시로코 기준, 한국어 전체 참고 원문과 날짜 계약을 적용했다. 검색 관련 스킬은 구현 범위 내 SEO/AEO/GEO 검수에 사용했다.

- 실제 상위 `/ko/airports/`의 BKK 카드 → 기존 BKK 대표 주소 링크를 보존했다. 새 세부 페이지에도 공항 목록 복귀와 수완나폼 공항안내 복귀 링크가 있다.
- 5개 페이지 모두 다른 4개 주제의 같은 시장 대표 URL을 초기 HTML의 실제 a 링크로 제공한다. 공항 안내 본문에도 시설·흡연실·시내 교통·카운터로 문맥에 맞는 연결을 넣었다.
- BKK 서비스가 있는 한국어 항공사 상세 9곳의 ‘이 공항의 항공사별 창구 보기’를 새 BKK 카운터 페이지로 연결했다. 카운터 페이지에서는 기존 실제 항공사·노선·공항쌍·운항 조회·대응 안내 링크를 유지했다.
- 시내 이동 상세의 상단·하단에도 같은 5개 페이지 연결을 넣어 공항↔교통 양방향 탐색을 제공한다. 공항철도·방콕 교통·돈므앙 환승 등 기존 실제 교통 연결은 유지했다.
- 도시·카메라·일정은 이 페이지 분리에 따른 새 관계 근거가 없어 추가 생성하거나 일괄 연결하지 않았다. 없는 번역·일정도 만들지 않았다.
- 관계 선정과 본문 문맥은 수동 검수했다. 범용 관계 자동 생성 엔진을 구현했다는 뜻은 아니다.
