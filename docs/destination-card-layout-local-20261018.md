# 목적지 카드 영역 정렬 — 로컬 검수

- 대상: `/ko/destinations/` 목적지 13개 카드. 태국 여행 메뉴에서 도시·섬을 고르고 해당 도시 지도로 이동하는 기존 목적과 한국어 이용자 범위를 유지한다.
- 사용자 요청: 방콕과 치앙마이의 설명 길이가 달라 사진 출처·‘지도에서 보기’가 어긋나는 문제를 영역별 CSS로 고정한다.
- 작업 전 AGENTS.md, page-seo-rules.md, SITE-DATES.md, page-generation-date-contract.md, operations-site-dates.md, INTERNAL-LINKING-CONTRACT.md를 확인했다. 한국어 원고·상세 본문 수정은 없는 레이아웃 작업이다.

## 변경

`src/components/TopicHub.astro`에서 한국어 목적지 그리드에만 전용 클래스를 추가했다. 카드의 사진·제목·설명·사진 출처·지도 링크를 다섯 개 공유 행으로 구성하고 CSS subgrid로 같은 줄의 영역 위치를 맞춘다. 설명 영역은 가장 긴 문장에 맞춰 늘어나므로 고정 픽셀 높이로 글을 자르지 않는다. 사진 출처가 없는 카드도 지도 링크는 같은 행을 사용한다. 링크 영역은 최소 44px이며, 카드에 마우스를 올렸을 때 위로 움직이던 효과를 제거했다. subgrid 미지원 환경은 세로 flex 배치로 하단 링크를 정렬한다.

한국어에만 적용한다. 기존 문장·사진·저작권·출처 URL·도시 ID·지도 이동 URL·상위 메뉴·메타 생성·공개 범위·날짜 데이터는 보존했다. 새 관계·상세·번역을 만들지 않았다. 스타일만 수정하므로 자료 확인일이나 본문 수정일·운영 배포일을 갱신하지 않았다.

## 검수 결과

- 기존 소스와 대조: 전용 클래스와 CSS 외의 본문·사진·링크 문자열이 동일하다.
- 실제 브라우저 CSS 너비 320, 390, 768, 1000, 1422px에서 13개 전체 카드 측정. 가로 넘침·설명/출처 잘림 없음. 같은 줄의 제목·설명 시작점·출처·버튼·카드 하단 좌표 차이 1px 미만.
- 1열 모바일, 2열, 3열 화면과 사진 출처가 없는 피피 카드 확인. 방콕 ‘지도에서 보기’ 클릭 시 `/ko/?city=bangkok#map`과 지도 요소 표시, 뒤로 가기 후 13개 카드 복귀 확인.
- 전체 테스트 40개 통과. 별도 전체 빌드 1,822페이지 생성, SEO 오류 0개·중복 제목/설명 0개, 날짜 바인딩 3,172개 감사 통과. 전체 긴 제목 등 경고 134개는 기존 다른 경로이며 이번 목적지 경고는 없다. 디자인 감사 issues 없음, 실제 Pages 런타임의 11개 시장 홈·데이터·미리보기 보호 검사 통과. 이번 레이아웃 클래스는 11개 시장 출력 중 한국어에만 존재함을 확인했다.
