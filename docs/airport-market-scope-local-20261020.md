## 사용자 확정 범위

## 구현과 보존

- 국가 선택 함수에서 원자료 시장과 대상 시장의 일치를 검사한다. 노선에 연결된 항공사와 관련 문의처를 선택하며 기존 브랜드 운항 상태 안내 URL은 유지한다.
- 한국어 항공사 검색은 한국 시장에 속한 카드만 생성한다. 다른 항공사는 공통 영어에서 검색한다.
- 공통 영어는 항공사 설명, 국가별 노선, 공항 카운터·연락처, 도움말을 함께 검색한다. 국가·종류 필터를 제공한다. 원문 언어의 전체 자료로 이동한다는 점을 명시한다. 원문 전체를 영어로 번역했다고 주장하지 않는다.
- 태국 공항 메뉴를 11개 언어에 연결한다. 한국어 허브의 기존 /ko/airports/ 경로와 국가별 기존 경로를 보존한다. 언어 전환 시 같은 공항의 실제 공개 경로로 연결하며, 존재하지 않는 외국어 세부 분할 페이지를 만들지 않는다.
- 공통 영어에 없었던 공항 목록과 4개 상세 경로를 추가한다. 시설 설명은 기존 검수된 영어 시설 자료를 재사용하며 미국의 입국·보험·노선 조건을 공통 공항 사실로 전용하지 않는다.
- 본문 사실, 공식 출처, 원자료 확인 기록, 이미지 권리 및 기존 URL을 보존한다. 새 자료조사·운영 배포·푸시·색인 제출은 실행하지 않는다.
