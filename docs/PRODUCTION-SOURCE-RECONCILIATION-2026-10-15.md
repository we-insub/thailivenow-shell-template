# 운영 소스 Git 정리와 안내·약관 배포

2026-10-15 사용자 요청. 운영 기준은 a2e72ca4, 운영 코드 커밋 302ecd76이다.

## 운영 소스 정리

- 현재 운영 페이지의 import graph와 배포된 공개 자산으로 파일을 선별했다. 조사 스크립트·다른 작업의 기획·QA 기록을 일괄 추가하지 않았다.
- 341개 후보 파일을 격리 디렉터리에 복사하고 고정한 기존 운영 메타데이터로 빌드했다. 생성 파일 1,927개가 기존 성공 배포 후보와 바이트 단위로 일치했다. 소스 기준 커밋은 81352776이다.
- 당시 운영에 없는 안내·약관 5개와 관련 코드 3개는 별도 제외했다. 이후 사용자가 이 5개를 편집·배포하도록 명시 승인하여 아래 변경으로 따로 포함했다.
- 공개 원본 CSV의 CRLF 및 기존 소스 공백은 운영과 동일한 바이트를 보존했다. 원본 형식의 diff whitespace 경고를 새 콘텐츠 변경으로 오인해 정규화하지 않았다.

## 승인된 신규 변경

- /ko/about/, /ko/contact/, /ko/credits/, /ko/terms/, /ko/privacy/와 한국어 푸터 연결.
- 확정 목적: 관광 여행자를 위한 태국 종합 여행 안내. 운영팀, hello@thailivenow.com, Gmail 연동, 문의 처리·삭제 기준, 향후 CPA 계획은 사용자 확인 문서를 따른다.
- 실제 구현과 안내를 맞추기 위해 방문 통계 동의 모듈을 연결한다. 동의 전·거부 상태에서 Google 태그를 불러오지 않으며, 허용·철회·닫기 동작을 유지한다.
- 사용자가 로컬에서 확인한 ‘허용 → 거부 → 닫기’ 순서를 그대로 포함했다.
- 신규 안내 페이지는 정보 확인일과 실제 수정일을 표시하고 배포일은 내부 릴리스 기록으로 구분했다. 기존 여행 페이지의 날짜 UI를 일괄 변경하지 않았다.
- 기존 카메라·페이지 확인 기록은 그대로 보존하고 새 5개 안내의 실제 검토·수정 기록만 추가했다.
