# 공통 SEO 적용·기존 페이지 점검 — 2026-10-14

## 적용과 자동화

page-seo-rules.md 공통 규칙을 작성하고 AGENTS.md 최상단에 전체 필수 읽기·적용·빌드 지침을 넣었다. npm build에 회귀 테스트와 전체 SEO 검사를 연결했다. 기술 검사가 전체 본문의 사실/문체/검색 의도 검수를 대신하지 않음을 명시했다.

## 기존 문제와 반영

- description 앞에 H1을 반복 삽입하던 공통 처리를 제거. 190자에서 조건/문장이 잘리던 처리를 제거.
- 홈페이지와 같은 소개가 들어간 여행지/쿠폰 허브를 실제 제공 정보로 수정. 비한국어 허브는 자신의 본문 소개를 사용.
- 공개 카메라의 크레딧 문구를 페이지 소개로 사용하던 fallback을 제거하고 원본/촬영 위치/시청 상태에 대한 해당 카메라 설명을 명시. 제목에 실제 페이지 기능인 언어별 카메라 정보를 포함.
- 항공편 설명의 항공사 공통값을 출발·도착지·편명·실제 운항 적용 범위가 있는 값으로 수정. 공항쌍은 양방향 연결 설명. 역은 실제 연결 노선, 선착장은 해당 명칭과 위치/보트 안내로 명시.
- 한국 항공사/보험 안내와 중국 확인서 안내에 기존 본문 근거를 토대로 페이지별 요약 17개 명시. 국가별 데이터·규정·출처·날짜는 변경하지 않음.
- 모든 상세 제목에 반복하던 일반 여행 키워드 제거. 영어 국가 페이지는 India/UK/US 시장 구분 유지. 타 언어 동일 명칭은 언어별 실제 페이지 주제를 명시.
- 페이지별 명시 OG 이미지 보존, 미지정은 브랜드 이미지 사용. WebPage 제목/설명/대표 URL을 최종 메타와 동기화하고 FAQ 사실은 유지.
- 언어 자동 이동 루트 /는 /en/ canonical과 noindex,follow로 정렬. 개인화·별칭 제외 정책 유지. 추가 미공개 제외를 위한 tln:indexing noindex 지원.
- Astro site 기본값 운영 도메인 고정으로 빌드의 canonical/언어 연결이 localhost를 가리키지 않게 함.
