# ThaiLiveNow 자연스러운 한국어 작성·검수 규칙

사용자 승인 기준: 2026-10-13 최종 시로코 원고. 정본은 `docs/sirocco-editorial-reference.json`에 저장한다. 모든 한국어 페이지의 제목·소개·본문·표·이용 안내·FAQ·카드 문구를 이 기준으로 비교한다. 루프탑·전망대뿐 아니라 입국·비자·공항·교통·음식·과일 등에도 적용한다. 다른 언어는 같은 설명 원칙을 해당 언어에 맞게 적용한다.

## 문장을 먼저 분석하고 다시 쓴다

1. 원문에서 확인된 사실과 여행자에게 주는 의미를 나눈다. 시간·연령·금지조건·가격·사진권리는 바꾸지 않는다.
2. 문장의 역할을 정한다: 방문 매력, 동행 추천, 장면 묘사, 이동 안내, 정책 답변. 모든 문장을 로맨틱한 소개로 만들지 않는다.
3. 독자가 떠올릴 수 없는 추상어를 찾아 구체적인 풍경·행동으로 바꾼다. “인상을 만드는 장면” → “골든돔 아래에서 야경을 보며 식사”. “날짜를 고르는 기준” → “재즈 공연이 있는 화~일요일에 방문”.
4. 정보의 의미를 독자의 방문에 연결한다. “나이 제한 없음” → “어린 자녀와 가족 식사를 즐길 수 있다”. “큰 짐 반입 불가” → “숙소에 짐을 두고 저녁 식사하러 가는 일정”. 없는 서비스는 만들지 않는다.
5. 한국어 화자가 실제로 쓰는 단어와 문장 순서로 다시 쓴다. “마지막 구간은 걸어서 이동” → “역에서 호텔까지 걸어가시면 돼요”. “전 연령 어린이를 받는다” → “나이 제한 없이 아이와 함께 갈 수 있어요”.
6. “~해요”를 붙이는 것만으로 자연화 완료로 보지 않는다. 사실의 순서와 장면·동행·선택 이유까지 연결한다. 딱딱한 규정 나열에 형용사만 추가하는 것도 반려한다.
7. 소개와 경험은 무엇이 매력적인지, 누구와 가면 좋은지, 어떤 시간을 보낼 수 있는지 보여준다. 추천은 편집 판단으로 쓰고 현지인/외국인 인기비율이나 방문 경험을 꾸미지 않는다.
8. FAQ는 질문의 답을 먼저 주고 이유·방문 장면·필요한 준비를 이어 설명한다. 본문을 같은 말로 반복하거나 “공식 안내 없음, 알아서 문의”로 빈 답변을 채우지 않는다. 모르는 항목은 화면에서 숨기고 gaps에 남긴다.
9. 복장·예약·시간·짐 규정은 이해하기 쉬운 예시를 붙이되 허용/금지와 추천을 구분한다. “정장·하이힐 필수”처럼 없는 조건을 추가하지 않는다.
10. “좋아요/추천해요/확인해주세요/겠죠/로맨틱”을 모든 문장에 반복하지 않는다. 문장마다 실제 새 정보나 장면이 있어야 한다. 소리 내 읽었을 때 여행을 소개하는 사람의 말처럼 이어지는지 확인한다.

## 사용자 예시를 통해 확인한 차이

- “골든돔과 야외 테라스가 시로코의 인상을 만드는 장면이에요”는 평론처럼 추상적이다. 골든돔·테라스·해 질 녘·식사하는 사람을 실제 장면으로 연결한다.
- “날짜를 고르는 기준이 될 수 있어요”는 독자와 거리가 있다. 공연요일과 동행자의 취향을 연결해 언제 가면 좋을지 바로 말한다.
- “당일 운영도 물어보세요”는 대상이 모호하다. 필요한 것이 재즈라면 “예약할 때 공연 시간을 물어보세요”처럼 정확히 쓴다.
- 복장은 “스마트 캐주얼”만 옮기지 않는다. “분위기 있는 저녁 약속에 입고 나갈 옷”과 셔츠·폴로·원피스·로퍼 같은 예시로 이해를 돕는다.
- 정책도 여행 장면에 맞춰 설명한다. 늦은 저녁은 문 닫는 시간과 주문 마감의 차이를 풀고, 짐 규정은 관광/쇼핑 후 숙소를 들르는 일정으로 연결한다.

## 시설별·언어별 적용

시로코 문구를 복사하지 않는다. 전망대는 풍경·산책·관람 경험, 바는 전망·음악·음료·동행, 레스토랑은 식사·분위기·기념일 등 실제 특성을 중심으로 쓴다. 모든 시설을 연인용/로맨틱 명소로 만들지 않는다. 각 언어도 한국어 어순을 직역하지 않고 현지 화자가 자연스럽게 느끼는 여행 소개로 쓴다.

시설별 editorialReview는 appeal/companions/experience/tradeoff/factEvidence/pass와 근거·시로코 비교 결과를 기록한다. pass=true 자기평가만으로 완료 처리하지 않고 Codex가 본문을 읽어 비교한다.

## 2026-10-14 사용자 확정: 전체 원문을 읽고 시로코와 직접 비교한다

사용자가 다시 제공한 **변경 전·후 전체 원문**은 [sirocco-user-full-reference-20261014.txt](./sirocco-user-full-reference-20261014.txt)에 수정·축약 없이 보존한다. 반복된 규칙도 원문 그대로 남긴다. 이 문서의 요약 규칙만 읽고 한국어를 작성하거나 검수 완료로 처리하지 않는다. 작업 시작 전에 전체 원문의 변경 전·후 문장과 아래 분석을 읽는다.

우선순위는 **최신 사용자 지시 → 사용자 제공 변경 후 문장과 전체 분석 원문 → 이 문서의 공통 적용 규칙**이다. 승인된 원고 데이터 `sirocco-editorial-reference.json`도 비교 자료로 사용한다. 두 자료의 차이를 발견하면 임의로 한쪽을 덮어쓰지 않고 차이를 기록한다. 사용자 원문과 달리 Codex가 일반화한 해석은 사용자 원문 자체로 표시하지 않는다. 아래 원인 분석과 작업 절차는 원문을 바탕으로 정리한 공통 적용 지침이며, 원문을 대체하지 않는다.

### 변경 후 문장이 자연스러운 이유 — 항목별 분석

1. **소개:** ‘저녁 한 번은 조금 특별하게’, ‘식사 자체를 하나의 일정으로’처럼 독자가 다시 해석해야 하는 표현을 ‘로맨틱한 저녁’, ‘특별한 저녁 식사’로 바꾼다. ‘부모님과 함께하는 여행’보다 ‘부모님을 모시고’가 식사하는 사람과 상황을 구체적으로 보여준다. 끝에는 ‘해가 지고 도시의 불빛이 하나둘 켜지는’ 모습을 넣어 어떤 시간을 즐기는지 떠올릴 수 있게 한다.
2. **경험 소개 1:** ‘인상을 만드는 장면’은 작성자의 평가이고 ‘도시가 밤으로 바뀐다’는 추상적이다. ‘시로코 하면 떠오르는 대표적인 풍경’, ‘해가 지고 방콕의 불빛이 하나둘 켜지는 모습’으로 독자가 이해할 풍경을 설명한다. ‘저녁 한 끼에 시간을 쓴다’보다 ‘저녁 한 끼를 여유롭게 즐긴다’가 방문 목적에 맞는 동사다.
3. **경험 소개 2:** ‘공식 FAQ에 따르면’이라는 조사 경위 대신 공연 요일을 먼저 알려준다. ‘날짜를 고르는 기준’ 대신 ‘공연이 있는 날에 맞춰 방문’이라는 행동을 제안한다. ‘당일 운영’ 대신 ‘당일 공연 시간’처럼 질문할 대상을 정확히 쓴다. 근거 링크는 하단에 보존한다.
4. **경험 소개 3:** ‘준비가 필요하다’로 끝내지 않는다. 운동복·큰 짐이 왜 문제가 되는지 설명하고 ‘숙소에 짐을 두고 옷을 갈아입은 뒤 방문’으로 이어준다. 조건을 불편함의 나열로만 쓰지 않고 실제로 가능한 방문 순서를 안내한다.
5. **어린이:** ‘전 연령 입장 가능’은 데이터 표기다. ‘나이 제한 없이 아이와 함께 방문할 수 있어요’는 여행자의 질문에 답한다. 연령 제한 없는 시설이라는 사실은 유지한다.
6. **예약:** ‘확인하면 방문 준비가 편해진다’는 결과만 말한다. ‘공식 홈페이지에서 미리 예약’, ‘예약할 때 예약금과 취소 조건 확인’처럼 어디서 언제 무엇을 할지 바로 설명한다.
7. **남성 복장:** ‘셔츠·폴로에 단정한 바지’라는 목록을 ‘셔츠나 폴로셔츠에 단정한 바지를 입고 가시면’이라는 자연스러운 문장으로 연결한다. 추천 복장과 실제 허용되는 반바지·샌들은 구분한다.
8. **여성 복장:** ‘격식 있는 샌들’보다 ‘외출용으로 갖춰 신는 샌들’이 읽는 사람이 옷차림을 떠올리기 쉽다. 하이힐이 필수가 아니라는 사실도 실제 준비에 연결한다. 이 예시는 시로코의 조건이며 다른 시설의 허용 복장으로 복사하지 않는다.
9. **금지 복장:** ‘피해주세요’는 권장처럼 읽힐 수 있다. 실제 금지라면 ‘입고 가실 수 없어요’, ‘금지되어 있어요’로 분명히 쓴다. 문체를 부드럽게 바꾸면서 금지를 선택 사항으로 바꾸지 않는다. 어린이에게도 적용되는 조건은 유지한다.
10. **대중교통:** ‘마지막 구간’, ‘차려입은 날’, ‘고려해보세요’보다 ‘역에서 내려 호텔까지 걸어가시면’, ‘하이힐을 신고 가신다면’, ‘Grab이나 Bolt로 호텔까지 이동’이 구체적이다. 하차 → 도보/차량 → 호텔 직원에게 목적지 전달 순서로 읽히게 한다. 확인되지 않은 출구·시간·거리는 추가하지 않는다.
11. **택시:** 앱에서 검색하는 행동과 택시 기사에게 문장을 보여주는 행동을 나누어 설명한다. 호텔에 도착한 뒤 누구에게 어떤 길을 안내받는지도 분명히 쓴다. 영문·태국어 목적지는 원본대로 보존한다.
12. **FAQ 동행:** 질문의 답인 연인·부모님을 먼저 말하고, 야경을 보며 식사하는 이유와 다음 일정에 쫓기지 않는 날이라는 선택 조건을 이어준다. ‘여행의 한 장면으로 남긴다’보다 실제로 누구와 무엇을 하는지 설명한다.
13. **FAQ 재즈:** 먼저 방문 요일을 답하고 야경·식사·재즈를 연결한다. 월요일의 예외를 남기고 예약할 때 물어볼 내용은 ‘연주 시간’으로 정확히 쓴다.
14. **FAQ 아이:** ‘네’로 답한 뒤 가족 식사, 나이 제한, 아이 옷차림을 설명한다. 같은 건물의 다른 바는 다른 규정일 수 있다는 예외도 유지한다. ‘전 연령 어린이를 받는다’ 같은 번역체는 쓰지 않는다.
15. **FAQ 복장:** ‘분위기 있는 저녁 약속에 입고 나갈 옷’으로 독자가 이해할 기준을 준 뒤 남녀 복장의 예시와 허용·금지 조건을 설명한다. 정장·하이힐을 필수처럼 오인하게 만들지 않는다.
16. **FAQ 예약·취소:** 날짜와 동행을 정함 → 시간 선택 → 예약금과 확정 조건 → 취소 기한 → 환불 불가 → 특별 행사/단체 예외로 연결한다. 원문의 ‘예약금은 식사 비용에서 차감’, ‘입금 확인 후 확정’은 문체 장식이 아니라 사실이므로 다른 시설에는 근거 없이 추가하지 않는다. **72시간 전까지와 72시간 이내**처럼 경계가 있는 표현은 공식 조건과 대조하고 뜻을 뒤집지 않는다.
17. **FAQ 늦은 식사:** ‘문을 여는 시간’과 ‘주문할 수 있는 시간’의 차이를 먼저 풀어준다. 세트·단품·스낵의 마감 시각을 구분하고 코스 식사를 원하는 여행자가 예약 시간을 정할 수 있게 설명한다. 시간 표기는 이해하기 쉬워도 자정과 날짜 경계를 혼동하게 바꾸지 않는다.
18. **FAQ 짐:** 반입과 보관 불가를 답한 다음 관광/쇼핑 → 숙소 → 저녁 방문 순서로 설명한다. 체크아웃한 날에는 어디에 짐을 맡길지 미리 정해야 한다는 실제 선택을 안내한다. 시설이 제공하지 않는 보관 서비스를 있는 것처럼 쓰지 않는다.

### 모든 한국어 페이지의 필수 작성 순서

1. **전체 기준 읽기:** 위 원문 전체와 이 문서를 읽고, 해당 페이지에서 비교할 시로코 항목을 고른다. 소개는 소개, 이동은 대중교통/택시, 이용 조건은 복장/예약/시간/짐, 질문은 FAQ와 대조한다.
2. **사실 정리:** 대상 국가·여권·장소·품종·적용 조건·기간·금액·예외·출처를 분리한다. 설명을 매끄럽게 만들기 위해 사실을 추가하거나 삭제하지 않는다. 한국 페이지에 다른 국가의 입국·항공사·연락처 조건을 섞지 않는다.
3. **초안의 어색함 분석:** 문장마다 누가, 어디에서, 무엇을, 언제 하는지 찾아본다. 추상적 명사, 번역 어순, 모호한 대상, 명사 목록, 조사 메모, 불필요한 반복이 무엇인지 기록한다.
4. **문장과 문단 재작성:** 독자의 질문에 먼저 답하고 상황 → 행동 → 이유/결과를 문맥에 맞게 이어준다. 모든 문장에 같은 순서나 세 요소를 억지로 채우지 않는다. 짧게 끝낼 답은 짧게 쓰고, 중요한 조건과 예외를 설명할 때는 필요한 길이를 확보한다. 함축하려고 유용한 설명을 삭제하지 않는다.
5. **사실 대조:** 재작성 전·후의 숫자·허용/금지·필수/권장·대상·예외를 비교한다. 특히 ‘피해주세요’와 ‘금지’, ‘신청 가능’과 ‘승인’, ‘최대 기간’과 ‘실제 허가’를 바꾸지 않았는지 확인한다.
6. **시로코와 본문 직접 비교:** ‘해요체인가’만 보지 않는다. 시로코 변경 후처럼 사람이 하는 말로 읽히는지, 풍경 또는 행동이 구체적인지, 문장이 다음 문장으로 자연스럽게 이어지는지, 독자가 실제로 선택하고 행동할 수 있는지 읽어 판단한다.
7. **수정 후 재검수:** 어색한 문장을 남긴 채 완료하지 않는다. 표현 검색은 보조 검사이며 통과 점수나 `pass=true`만으로 자연스러움을 확인한 것으로 처리하지 않는다.

### 입국·비자·공항·교통·음식에 적용하는 방법

- **입국·비자:** 여행자의 여권과 방문 목적을 먼저 밝히고 준비할 서류·작성 시기·제출 위치·도착 후 순서로 설명한다. 시로코의 구체적인 행동 설명을 적용하되 야경·로맨틱 분위기를 억지로 넣지 않는다. ‘준비가 편해져요’로 마무리하기보다 실제로 준비할 것을 알려준다.
- **공항·교통:** 어느 층/역/승차 위치로 가서 무엇을 보여주거나 구매하고 어디에서 내리는지 설명한다. ‘마지막 구간’, ‘이동 수단을 고려’보다 확인된 장소와 행동을 쓴다. 노선·요금·운행 조건은 국가와 운영사별로 구분한다.
- **음식·과일:** 재료·향·식감·먹는 방법을 독자가 떠올리기 쉬운 말로 설명한다. ‘맛의 구성을 살펴보세요’ 대신 어떤 재료를 어떻게 먹는지 쓴다. 모든 음식에 같은 감탄이나 추천 문장을 복사하지 않는다. 품종·산지별 제철, kg/송이/팩 가격 단위, 실제 사진과 라이선스를 섞지 않는다.
- **허브·카드·표:** 짧게 써도 행동이나 특징이 구체적이어야 한다. 가격·시간처럼 간결한 데이터 자체가 가장 명확한 항목은 억지로 해요체 문장으로 늘리지 않는다. 본문이 필요한 조건을 설명한다.

### 말투와 반복의 판단 기준

사용자 승인 문장에 있는 ‘좋아요’, ‘추천해요’, ‘겠죠’, ‘답니다’, ‘로맨틱’은 금지어가 아니다. **해당 상황에 어울리게 사용하는 것이 기준**이다. 모든 문장을 같은 어미로 끝내거나 같은 매력을 반복하면 다시 쓴다. 자연스러움을 만들기 위해 반말·과장·가짜 방문 후기·근거 없는 인기나 효능을 추가하지 않는다. 원문의 따뜻한 말투와 충분한 설명을 과도한 축약이나 건조한 요약으로 바꾸지 않는다.

### 작성·검수 기록

작업 기록에는 읽은 기준 파일, 비교한 시로코 항목, 어색했던 문장과 원인, 변경 후 문장, 보존한 사실·조건·예외, 미확인 사항을 남긴다. 기존 시설별 `editorialReview` 필드는 유지하고 정보성 페이지에는 방문 매력/동행을 억지로 채우지 않는다. 기록은 내부 문서에 두며 사용자 화면 본문에는 검수 용어나 작성 절차를 넣지 않는다.

문서 규칙만으로 모든 문장의 자연스러움이 자동 보장되는 것은 아니다. **모든 한국어 작성·수정에서 원문을 읽고, 사실을 지키며, 문장 자체를 비교·재작성·재검수하는 절차를 필수로 수행한다.**
