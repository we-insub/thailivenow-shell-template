# 한국어 공항 지도 조작 변경 — 로컬 검증

사용자 요청: 수완나폼(BKK), 돈므앙(DMK), 푸켓(HKT), 치앙마이(CNX)의 지도 확대 슬라이더를 제거하고 지도 위에서 휠 확대·축소와 드래그 이동을 제공한다.

- 네 공항의 기존 한국어 상세 URL에 공통 적용했다. 층 선택, 시설 안내, 지도 핀, 기존 자료와 출처는 유지했다.
- 휠 위치를 기준으로 확대·축소하고 마우스로 드래그해 이동한다. 모바일 두 손가락 확대·축소와 이동을 구현했다.
- 키보드 +/− 확대·축소, 방향키 이동, Home 초기화를 지원한다.
- 공통 CSS와 충돌하던 지도 캔버스 클래스명을 변경해 이미지와 핀이 같은 좌표계를 사용하도록 했다.

## 검증

- 실제 PC 브라우저에서 네 공항 모두 휠 확대와 드래그 이동 성공, 슬라이더 0개 확인.
- 모바일 390×844에서 네 공항 모두 가로 넘침 없음과 지도 touch-action 설정 확인. 실제 터치 기기의 두 손가락 동작은 미검증이며, 이동하는 중심점에 대한 핀치 계산은 단위 테스트로 확인했다.
- 전체 테스트 44개 통과. 전체 빌드 1,822페이지, SEO 오류 0개(기존 경고 134개), 중복 제목·설명 0개.
- 날짜 테스트 9개 및 날짜 감사 통과. Pages 로컬 런타임 검사 passed=true. 디자인 감사 1,822페이지 issues=[] 확인.
- 로컬 Pages 4338 포트의 네 상세 URL 모두 HTTP 200, 지도 뷰포트 존재 및 확대 슬라이더 제거 확인.
- 브라우저 결과와 화면: artifacts/airport-map-gestures-20261018/의 checks.json, mobile-checks.json 및 공항별 PNG.

운영 배포는 수행하지 않았다. 기존 지도·사진의 운영 공개 보류 조건은 유지한다.
