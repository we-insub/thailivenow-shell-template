# 작업 담당 및 검수 규칙

사용자 합의: 2026-10-12

## 담당 지정

- 사용자가 Codex에게 요청한 작업은 Codex가 직접 수행한다.
- 사용자가 뮤즈를 언급해 맡긴 작업만 태국 전용 뮤즈 채팅에 전달한다. 모든 요청을 자동 위임하지 않는다.
- 뮤즈를 사용하는 경우 Codex가 요구사항을 구체화하고 결과를 검수한다.
- 다른 컴퓨터에서 진행하는 일본·한국 작업과 섞지 않는다.

## 뮤즈 작업 지시

지시에는 목표, 현재 상태, 변경 범위, 유지할 기존 동작, 완료 기준을 포함한다. 사용자가 생략한 필수 사항은 작업에 맞게 보완한다.

웹 기능은 관련 페이지·언어·URL 분기, PC·모바일 표시, 상태 유지, 접근성, 기존 기능 영향을 확인하도록 요청한다. 다국어 작업은 브라우저 언어 감지, 수동 선택 저장·초기화와 지역별 메타데이터·hreflang·canonical의 적절성을 포함한다. 아직 구현하지 않은 사항을 완료로 보고하지 않는다.

자료 조사는 출처 URL, 확인 날짜, 사용 조건, 중복·제외 사유와 미확인 사항을 제출하도록 요청한다. 무료 열람과 재사용 허용을 구분한다.

## 결과 전달 및 검수

명소·교통 상세페이지 제작 지시와 검수에는 [공통 템플릿 규칙](detail-template-rules.md)을 포함한다. 기본 틀은 유지하되 정보가 없는 항목·표 행·빈 섹션은 화면에서 제외한다.

뮤즈는 실제 수정 파일 또는 적용 가능한 패치와 짧은 결과 보고를 제출한다. 보고 항목은 변경 파일, 검증 방법·결과, 남은 문제다. 로컬 파일에 접근할 수 없다면 그 사실과 파일 전달 방법을 먼저 밝힌다.

Codex는 전달받은 변경을 검토하고 로컬에서 필요한 빌드와 주요 동작을 확인한다. 화면 변경은 PC·모바일에서 확인한다. 오류는 뮤즈에 구체적으로 수정 지시한다. 검수 범위와 미확인 사항을 사용자에게 정확히 보고한다.

## 토큰 절약

작업은 의미 있는 단위로 묶어 전달한다. 긴 채팅·전체 소스의 반복 읽기와 잦은 진행 확인을 줄이고, 변경 부분과 핵심 실행 결과를 중심으로 검수한다. 절약을 이유로 필수 검증을 생략하지 않는다.
