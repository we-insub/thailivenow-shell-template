# 지연·결항 허브 중복 목록 정리 — 로컬 검증

사용자 요청: 태국 공항으로 옮긴 내용은 지연·결항 메뉴에서 중복으로 표시하지 않는다. 대상은 한국어 `/ko/airport-assistance/`이다. 운영 배포는 하지 않았다.

## 반영

- 수완나폼·돈므앙·푸켓·치앙마이 소개 카드, 해당 공항 선택 카드, 연결 노선 44건, 현지 창구 33건의 중복 목록을 제거했다.
- 공항 카운터 찾기와 네 공항의 늦은 도착 후 이동 안내는 허브 목록에서 제외했다. 해당 상세 및 공항 페이지의 문맥 링크는 유지했다.
- 지연·결항·수하물 사고·여행보험·승객 권리와 항공사별 대응 안내를 유지하고 제목·설명을 실제 내용에 맞췄다.
- 아직 이동하지 않은 한국 출발공항 3곳과 창구·문의처 40건, 다른 시장 페이지는 유지했다. 태국 공항 안내로 가는 실제 HTML 링크를 제공한다.
- 원본 데이터, 상세 URL, 공식 근거·자료 확인일·배포일은 보존했다. 신규 자료조사는 하지 않았다.

## 검증

- 전체 테스트 51개 통과.
- `npm run build` 성공: 1,825페이지, SEO 오류 없음. 날짜 감사 3,204개 바인딩 오류 없음.
- `npm run check:runtime` 통과. 전체 디자인 감사 이슈 없음. `git diff --check` 통과.
- 초기 HTML에서 태국 공항 소개·노선 목록 및 이동 안내 5개가 제외됐고, 한국 공항 3곳·창구 40건과 사고 대응 안내가 유지됨을 확인했다. 태국 공항 허브의 네 공항 링크 및 상세 경로도 유지됐다.
- 실제 개발 브라우저 PC·390px 모바일 확인: 지연·결항 내비게이션 활성, 인천 검색 정상, 가로 넘침 없음.
- 증빙: `artifacts/disruption-hub-cleanup-20261018/`의 HTML 점검 JSON과 PC·모바일 화면.

로컬 구현·검증 결과이며 운영 배포·검색엔진 색인·노출 결과를 뜻하지 않는다.
