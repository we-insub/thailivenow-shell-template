# 항공편 지연·결항 안내 다국어 메타 검수 — 2026-10-24

## 사용자 확정 범위와 목적

`/ko/airport-assistance/`와 지원 11개 언어·시장의 같은 서비스에서 발견한 hreflang 누락, 일본어 메타의 생략형 문장, 미국식 표기, 제목의 국가명 중복을 수정한다. 해당 서비스의 실제 질문은 태국 여행 중 항공편·수하물 사고가 났을 때 무엇을 먼저 하고 어떤 항공사·공항·보험 안내로 이동해야 하는지다. 지연·결항 메뉴 소속과 기존 국가별 데이터·본문·출처·날짜·URL·미커밋 작업을 보존하며 배포하지 않는다.

공통 영어 `/en/airport-assistance/`는 10개 국가의 자료를 찾는 별도 통합 검색 디렉터리다. 10개 국가별 지연·결항 허브와 동등한 번역 페이지라고 표시하지 않는다. 실제로 같은 진입 질문에 답하는 10개 국가 허브끼리 초기 HTML의 hreflang을 상호 연결하며 각 페이지의 자기 참조를 포함한다. 별도의 동등한 공통 영어 허브가 없어 이 그룹에는 en/x-default를 추가하지 않는다. 기존 태국 공항 공통 안내의 11개 언어 hreflang은 유지한다. 국가별 출발공항·노선·보험 청구 상세는 서로 번역 페이지로 묶지 않는다.

## 수정

- 공통 SEO 경로에서 10개 국가 허브의 hreflang을 생성한다. 실제 지원 경로와 언어 태그를 사용하며 반복 처리에도 태그가 중복되지 않는다.
- 공항 안내의 제목에 이미 India/Indian, UK/United Kingdom, US/USA/United States가 있으면 브랜드 뒤에 같은 국가 표기를 덧붙이지 않는다. 일반 제목의 시장 표기와 공항 밖의 기존 제목 정책은 유지한다.
- 일본어 메타 23건의 생략형 끝맺음·중간 문장을 완전한 문장으로 고쳤다. 메인 설명은 157자에서 162자가 됐다. 영국·인도·스페인 메인 설명 3건도 완전한 문장으로 보완했다. 변경 전후 26건의 수치가 같다.
- 미국 허브·사고 안내·FAQ·직원 요청 문장에 canceled, traveled/traveling, itemized, organization을 적용한다. 영국·인도 및 공통 영어 원문은 보존한다. `flight-cancelled`를 포함한 ID와 URL, 태국어 요청 원문, 전화·이메일·공식 출처를 바꾸지 않는다.
- 미국 원자료는 편집하지 않았다. 기존 편집 오버레이에 문장 6건을 등록해 화면용 철자만 바꾼다.
- 언어별 JSON에 없던 기존 상세 설명 102건은 이미 표시되던 설명 그대로 등록했다. 본문 소개를 메타용 문장으로 덮어쓰거나 날짜·요금·조건을 새로 만들지 않았다. 다른 작업에서 먼저 등록한 키는 덮어쓰지 않았다.
