## 문장 비교

- 카타의 기존 소개는 “카타 야이로도 불리는 … 카타 노이와는 다른 해변이니 … 이름을 구분해주세요”로 끝났다. 구분이라는 준비 지시보다 굽은 만과 모래사장, 주변 식당을 친구·연인과 즐기는 장면으로 소개를 다시 썼다. 카타 노이와의 구분은 기본 정보·경험·FAQ에 보존했다.
- 차웽의 기존 경험은 “수상 활동이 소개되는 해변이지만 … 확인해주세요”였다. 흰 모래사장을 걷고 숙소 앞에서 쉬는 날과 다른 구간을 둘러보는 날을 연결했다. 수상 기구와 수영 구역 구분은 경험·입수 안내에 남겼다.
- 낭통의 “지방자치단체는 … 특징으로 소개해요”는 조사 경위였다. 검은 모래가 섞인 부분과 바다 가운데 낭통 바위를 직접 바라보는 행동으로 바꾸었다. 저조 때 지면이 드러나도 항상 걷는 길이 아니라는 예외는 별도 경험 카드와 FAQ에 충분히 설명했다.
- 라일레이의 “이 안내에서는 … 경로를 소개해요”라는 답은 실제 행동이 흐렸다. 아오낭에서 배를 이용하고 도착 해변과 귀가 약속을 정하는 순서로 답했다. 이스트의 진흙 해안·암벽 활동과 웨스트의 흰 모래사장 차이는 유지했다.
- FAQ는 질문에 먼저 답하고 이유와 이동·방문 선택을 이어 설명하도록 19곳 모두 수정했다. 기존 빨간 깃발 수영 금지 답변은 의미·문장 그대로 보존했다. 근거 없는 가족 수영 안전 보장, 체험 후기, 인기 수치, 운항 시간과 요금은 추가하지 않았다.
