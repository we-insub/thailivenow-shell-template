# 안내 그림(다이어그램) 다국어 제작 규칙 — 2026-10-23 사용자 확정

열차 이용 안내(`/ko/transport/guides/train/`)의 단계별 그림에서 시작한 규칙이다. 앞으로 모든 지원 언어·시장의 안내 그림에 같은 방식을 적용한다. 그림은 SRT 등 외부 사이트 화면을 복사하지 않고 확인한 배치를 단순화해 직접 그린다(사용권 근거 확보 전에는 외부 화면 캡처를 쓰지 않는다).

## 확정한 5가지

1. **도형은 고정하고 글자만 교체한다.** 상자 위치·크기, 화살표, 번호 배지, 캔버스 크기는 모든 언어에서 같다. 상자 안 문구만 언어별 사전에서 가져온다.
2. **글자가 상자를 넘치지 않는지 자동으로 잰다.** 실제 폰트로 글씨 폭을 재서 상자보다 넓으면 줄을 나누거나 글씨를 줄인다. 그래도 들어가지 않으면 생성이 실패하고 빌드가 막힌다. 눈으로만 확인하지 않는다.
3. **글자를 윤곽선(도형)으로 바꿔 저장한다.** SVG 글씨는 기기별 폰트에 따라 달라지므로 어떤 기기에서도 같게 보이도록 윤곽선으로 변환한다. 그림 속 문구는 `<img alt>`와 본문 설명(번호 범례·표)에 따로 있어야 한다. 접근성을 윤곽선 글자에 맡기지 않는다.
4. **언어별로 알맞은 폰트를 쓴다.** 한국어·일본어·중국어(간체·번체)·태국어·키릴·라틴 글자를 각각 맞는 폰트로 처리한다. 폰트는 재배포 가능한 라이선스(OFL 등)만 쓰고 출처와 라이선스를 기록한다.
5. **한국어 확정 후 내린다.** 한국어 그림과 본문을 사용자가 먼저 검수·확정한 뒤 언어별로 생성한다. 확정 전에 다국어 그림을 만들지 않는다.

## 구현 기준 (생성기를 만들 때)

- **형태:** 그림마다 `layout`(도형·좌표·글씨 상자)과 언어별 문구 사전을 분리한다. 문구 사전은 언어당 한 파일이고 키는 모든 언어가 같다.
- **글씨 규칙:** 기준 글씨 크기에서 시작해 줄바꿈(최대 2줄)과 축소(기준의 75% 이상)를 순서대로 시도한다. 그래도 넘치면 오류로 끝낸다.
- **출력:** `public/images/transport/train/<그림>.<언어>.svg`. `en-us`·`en-gb`·`en-in`은 같은 영어 그림을 공유하되, 영어는 D-Ticket 영어 화면의 실제 단어(Northern line, Origin 등)를 사용한다.
- **검사:** (a) 모든 언어의 도형 좌표·개수가 같은지 비교, (b) 모든 문구 키가 모든 언어에 있는지, (c) 글씨가 상자 안에 들어가는지, (d) 언어별 alt가 있는지. 하나라도 실패하면 빌드가 막힌다.
- **재생성:** 그림 구조를 바꾸면 영향받는 모든 언어를 다시 생성하고 검사한다.
- **번역:** 언어별 문구는 직역하지 않고 그 시장의 자연스러운 표현으로 쓴다. 다른 나라 사이트 UI의 고유 명칭(메뉴 이름)은 실제 화면의 표기를 그대로 쓴다.

## 현재 상태

- 한국어 그림 4개(첫 화면 검색 칸, 예매 순서, 결제 방법, 위쪽 메뉴)는 프로그램으로 그린 SVG이며 `public/images/transport/train/`에 있다. 글씨는 아직 윤곽선이 아니라 시스템 폰트 텍스트다. 이 규칙의 2~4번은 다국어 생성기에서 구현한다.
- 생성기·사전·검사는 아직 만들지 않았다. 한국어 검수가 끝난 뒤 구현한다.
