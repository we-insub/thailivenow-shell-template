# 음식 섹션 한국어 재작성·사진 검수

사용자 지시: 붙여넣은 전후 원고를 함축하지 않고 읽고, 자연스러운 이유를 분석한 뒤 모든 음식 페이지에 적용. 원문 전체는 `food-sirocco-user-reference-20261014.txt`에 그대로 보존했다. `natural-korean-copy.md`와 시로코 정본을 함께 비교했다.

## 원인과 적용

기존 음식 원고의 문제는 해요체 여부가 아니라 설명의 대상과 연결이었다.

1. `한 끼를 고르다`, `구성을 살펴보다`, `메뉴에 따라 달라요`가 반복돼 실제 음식의 모습과 매력이 약했다. 시로코는 골든돔·테라스·해가 지는 모습을 명시한다. 음식도 굵은 노란 면, 해산물, 바삭한 면, 토마토 소스와 채소처럼 눈앞에 그려지는 재료로 썼다.
2. `푸켓식 면 요리의 하나로…한 그릇의 맛이 달라져요`는 무엇을 먹는지 말하지 못한다. `굵은 노란 면에 해산물과 소스를 넣고 센 불에서 볶아낸 음식`으로 재료와 조리 행동을 먼저 설명한다. 실제 미 호끼엔 근거는 태국 정부 홍보국 자료로 유지한다.
3. `맛을 살펴보세요`, `식사를 구성하세요`는 행동이 불분명하다. `튀긴 면이 국물에 젖기 전에 한입`, `로띠를 펼치고 설탕실을 올려 말기`, `밥에 커리와 건더기를 조금씩 얹기`처럼 독자가 바로 따라 할 수 있게 바꿨다.
4. 출처를 설명하는 조사 메모가 음식 이야기보다 앞섰다. 음식의 맛과 독자의 식사 경험을 먼저 설명하고, 공식 근거 링크는 하단에 보존했다. UNESCO 등 정보 자체가 중요한 경우에는 정확한 등재 대상·연도를 본문에 유지했다.
5. 막연한 여행자 대상 대신 혼자 간단히 먹을 점심, 친구·가족과 나눠 먹는 식사, 더운 날 구시가지에서 쉬어 가는 간식처럼 선택 이유를 연결했다. 방문한 척하거나 현지인의 인기 비율은 만들지 않았다.
6. FAQ는 `아니요/네/매운맛이 있어요` 등 답을 먼저 주고, 먹는 방법과 재료를 이어 설명한다. 확인되지 않은 레시피·가게·가격으로 채우지 않았다.
7. 규칙·예외는 보존했다. 새우와 양념, 동물성 조미료, 채식·할랄 판단, 날고기 라프, 판매 단위, 도시의 발상지와 전국 음식 구분을 삭제하지 않았다.

범위: 음식 메인 1, 전통음식 소개 1, 도시 허브 6, 음식 상세 20. 합계 28페이지. 공통 카드·소개·기본정보·먹는 방법·FAQ·출처 안내도 재검토했다. 데이터의 editorialReview와 sources/evidence를 함께 유지한다.

## 사진

실제 음식 사진 16개를 Wikimedia Commons 파일별 원저작자·라이선스·음식 설명을 확인해 선택했다. 파일명만으로 선택하지 않고 연락 사진판과 실제 사진을 검수했다. 음식 예시로 표시하며 특정 도시의 식당 사진이라고 주장하지 않는다. 그린 커리는 로띠, 라프는 오리라는 사진 속 형태도 캡션에 설명한다. 원본 링크·사진명·원저작자·정확한 CC 버전·라이선스 링크·크기 조정/카드 표시 잘림을 사진 옆에 항상 표시한다. BY-SA 사진은 해당 라이선스로 제공한다. 파일별 메타데이터는 `artifacts/food-selected-photo-metadata.json`, 배포 파일의 크레딧은 `public/images/food/credits.json`에 보존했다.

미 호끼엔·미 훈·아우 쁠라·핫야이 닭튀김은 정확한 음식과 공개 재사용 권리를 함께 확인할 사진을 확보하지 못해 사진을 넣지 않았다. 일반 볶음면·다른 나라 호끼엔 면·중국계 과자·일반 닭고기 사진으로 대신하지 않는다. 확인되지 않은 사진 자리는 화면에 만들지 않고 gaps에 기록한다.

TAT Media Assets의 추가 후보는 https://tatmediaassets.com/terms 에서 사전 개별 허가가 필요한 것을 확인했다. 승인 없이 사용하지 않았다. 외부 연락·허가 신청은 수행하지 않았다.
