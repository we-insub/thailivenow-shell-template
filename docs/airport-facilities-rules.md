# 공항 상세 시설 안내 적용 지시

## 공항 안내의 내비게이션 소속 — 2026-10-18 사용자 확정

한국어 태국 공항 목록에서 들어가는 BKK·DMK·HKT·CNX 안내와 수완나폼 1~5번 페이지는 계속 ‘태국 공항’ 메뉴에 속한다. 기존 주소에 airport-assistance 또는 transport가 포함되어 있어도 지연·결항이나 교통 메뉴로 선택 상태를 바꾸지 않는다. 상단 복귀·상위 안내도 실제 공항 목록/수완나폼 안내로 연결한다. 지연·결항 메뉴의 콘텐츠 재구성은 추후 별도 작업이며 이번에 시행하지 않는다. 기준 구현은 `src/lib/airport-guide-navigation.mjs`다.

사용자 승인: Muse 조사자료를 Codex가 검수하고 각 태국 공항 상세페이지 맨 위에 상세 시설 안내를 적용한다. 기존 항공사·노선·서비스 자료 및 URL은 유지한다. 운영배포는 별도 요청 전 하지 않는다.

## 페이지 구성

공항 소개 → 공식 층별 지도 → 도착 / 출발 / 환승 안내 → 편의시설 찾기 → FAQ → 기존 항공사·노선 안내. 시로코의 상세 디자인과 자연스러운 문장 기준을 사용하되 공항 이용 목적에 맞춘다. 터미널/층/일반구역·보안구역과 접근조건을 명확히 표시한다. 시설 카테고리·층·터미널로 찾기 쉽게 구성하고 공식 지도와 상세 위치를 연결한다.

## 자료 및 검수

완료된 실제 자료부터 회수한다. 공식 출처·확인일·원문 근거·위치·시간·비용·지도 사용권을 확인한다. 미확인 자료를 임의로 채우지 않고 기존 담당의 진행과 겹치는 조사를 재시작하지 않는다.

## 다국어

한국어 및 기존 지원 en/en-gb/en-us/en-in/ms/zh-cn/zh-tw/ja/ru/es. 사실은 같은 검증 자료에서 재사용한다. 외국어 제목·문장·표·버튼·FAQ에는 괄호 한국어 해석을 표시하되 원문과 해석을 별도 필드로 저장한다. 기존 src/lib/airport-review.ts의 airportKoreanReviewEnabled 단일 설정으로 제거 가능하게 통합한다. 한국어 페이지에는 중복 해석을 표시하지 않는다.

PC·모바일, 필터·지도 링크·기존 노선 링크, 문장별 한국어 해석 누락과 비활성화 시 제거를 확인한다. 새 자료가 아직 도착하지 않은 단계에서 적용 완료로 보고하지 않는다.

## CAAT 및 다국어 시장별 데이터 (사용자 추가 확정)
언어 번역만으로 다른 국가 페이지를 만들지 않는다. CAAT 공통 법규 근거는 공유하되 예시 목적지·귀국 노선·실제운항 항공사·카운터·연락처·확인서·보험 링크는 airportMarketData(locale)의 해당 국가 자료를 사용한다. 영어 지역별 시장도 분리한다. 한국어 한국행 예시와 한국 항공사/보험사를 다른 시장에 그대로 복제하지 않는다. src/components/AirportGuideAirlines.astro는 이미 locale별 노선 운항사와 현지 안내를 선택한다. 향후 CAAT 공통 디자인 이식에서도 이 분리를 유지하고 문장별 한국어 임시해석을 함께 표시한다.

## 사용자 층별지도 수집 지시 변경
공식 공항 홈페이지에 직접 들어가 실제 층별지도 이미지/PDF 원본을 내려받고 BKK/DMK/HKT/CNX 공항별 폴더와 ZIP으로 제출한다. 존재여부 검색·상태JSON 반복보다 실제 파일 수집을 우선한다. 터미널·층·원본URL·출처페이지·확인일·사용권표기 manifest를 함께 보존한다. 일반사진/홍보이미지/추정그림으로 대체하지 않는다. 다운로드와 홈페이지 게시권은 구분하며 게시권 미확인은 원본보관/공식링크로 처리한다. 기존담당·실행 유지, 실패경로 반복·중복worker 금지. 단일담당에 실제전송·실행 확인까지 요청했으며 본 채팅에서 중복 Muse조작하지 않는다.

이 문서는 기존 지시의 제작 규칙만 이식했다. 개인 조사 대화·회수 로그는 개발 의존성이 아니며 원본 작업 파일은 로컬에 보존한다.

## 2026-10-19 국가별 화면 승인·검수 해석 제거

사용자 최신 지시로 국가별 지연·결항 허브를 한국어 승인 화면의 구성에 맞추고 각 국가의 기존 데이터를 배치한다. 외국어 화면에 붙이던 괄호 한국어 검수 해석은 제거한다. `airportKoreanReviewEnabled=false`를 사용하고, 별도 템플릿에서 출력하던 소개·FAQ·터미널·날짜·직원 요청 문장의 검수 해석도 동일 설정을 따른다. 현지어 본문·태국어 실제 요청 문장·원본 출처·검수 사전은 보존한다. 앞의 임시 괄호 해석 표시 지시보다 이 최신 사용자 승인이 우선한다. 로컬만 수정하며 운영 배포하지 않는다.
