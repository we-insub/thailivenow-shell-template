# 네 공항 한국어 상세 재작성·층별 이미지·흡연구역

## 사용자 확정 범위

수완나품 BKK·돈므앙 DMK·푸껫 HKT·치앙마이 CNX의 기존 한국어 상세를 상세페이지 규칙에 맞춰 재작성한다. 지도 뷰어만 붙여 끝내지 않고 실제 확보 가능한 지도·사진과 층/터미널/일반구역·출국심사 후 구역을 구분한 시설 안내를 제공한다. 흡연구역과 찾아가는 기준점은 근거가 있는 위치에만 빨간 핀을 표시한다. 기존 한국어 우선 범위를 유지하며 운영배포는 하지 않는다.

목적: 처음 이용하는 한국어 여행자가 현재 위치에서 어느 층·시설로 이동할지 결정할 수 있는 공항 상세. 기존 `/ko/airports/` 메뉴·목록에서 `/ko/airport-assistance/airports/{bkk,dmk,hkt,cnx}/` 정본으로 들어가고 목록으로 돌아오는 구조를 보존했다. 기존 한국↔태국 항공사·노선·공항쌍·철도/공항 이동·수하물 가이드 연결도 보존했다. 같은 도시의 모든 카메라나 없는 일정·언어판을 추가하지 않았다. 초기 HTML의 상위↔상세·정본·링크 대조는 수동이며 새 관계 엔진은 만들지 않았다.

## 적용 기준·사실 보존

detail-template-rules, airport-facilities-rules, INTERNAL-LINKING-CONTRACT와 앞서 읽은 page-seo-rules, natural-korean-copy, sirocco-user-full-reference 전체, SITE-DATES 및 관련 날짜 명세를 적용했다. 비교 항목은 시로코 소개·대중교통/택시·기본정보·질문에 답한 뒤 행동을 설명하는 방식이다.

기존 시설 자료의 숫자·시간·요금·예외·지원 항공사·출처는 원본 JSON을 수정하지 않고 유지했다. 한국어용 별도 데이터 `src/data/airport-detail-guides-ko.json`으로 소개→기본정보/사진→층별 지도→흡연→도착/출발/환승→시설검색→기존 세부 안내→FAQ/출처를 구성했다. CNX의 ‘~입니다’·붙어 있던 문장·명사식 이동 안내를 자연스러운 해요체와 실제 행동으로 풀되 가격·구간·기기 수·항공사는 유지했다. 항공사 재조사·원어민 다국어 전수검수로 확대하지 않았다.

새 구성: `AirportKoreanGuide.astro`, `AirportGuideMap.astro`, `src/scripts/airport-detail-guide.ts`. `AirportFacilityIntro.astro`에서 한국어에만 새 상세를 렌더링한다. 비한국어 시설 원고·문장쌍·한국어 검토 스위치 설정은 보존한다. 본문 출처 번호·목차를 새로 노출하지 않으며, 공식 출처와 현장 후기·보도를 별도 기본 닫힘 details로 제공한다.

## 실제 회수

각 공항 공식 `/airport-map`에 들어가는 실내지도 앱의 공개 GraphQL 쿼리·응답으로 구역·층·이미지 URL·시설 목록을 회수했다. 앱 실제 UI에서 터미널/층을 선택하고 표시 이미지 URL이 응답과 일치하는지 대조한 다음 브라우저의 이미지 다운로드 기능으로 SVG 원본을 받았다. 인증·보안 차단을 우회하지 않았다. 이전 urllib403과 실제 브라우저 이미지 다운로드 성공을 구분한다.

공식 about-us의 실제 공항 소개 사진4장을 추가 회수·육안 대조했다. 원본은 2021년 파일명이며 촬영일은 알 수 없다. 현재 시설 운영 사진이라고 주장하지 않고 공항 공식 소개 사진으로 표시했다. 원본 JPG 보존 및 WebP4장을 로컬 표시한다.

원본·다운로드 기록·해시·지도 구역/층·원본 URL·사용권 상태: `artifacts/airport-detail-rewrite-20261018/asset-manifest.json`, `map-receipt.json`, `maps/`, `photos/`, `airport-map-and-photo-originals.zip`. 기존 원본과 다른 작업 QA를 삭제·복원·커밋하지 않았다.
