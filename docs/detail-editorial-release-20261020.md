# 상세 저자·날짜·공유 이미지 적용 기록

사용자 승인: 모든 지원 언어 상세에서 기존 원고·사진·사실·정본/내부 URL·원출처·검수 기록을 보존하며 공통 정책 적용 후 선별 커밋·푸시·정식 운영 배포한다. 새 자료 조사·색인 제출·검색 및 AI 노출 보장은 범위에 없다.

기준 운영: da82d7c2dbfa1b6eb1ab440e53cfb92d4af13a9c. 기존 지도 및 180일 방문 통계 선택 저장 배포를 포함한다. 작업 checkout의 다른 미커밋 원고·자산·QA를 릴리스에 포함하지 않는다. 별도 Git index로 기준 운영 커밋 위에 이번 변경 파일만 커밋한다.

## 구현

- 공통 SEO 변환에서 모든 지원 언어 상세 H1 직후 현지 언어 byline, author 메타, 페이지 author/publisher 조직 연결을 한 번만 생성한다. 외부 VideoObject/ImageObject 및 creator/provider/citation과 기존 FAQ를 수정하지 않는다.
- RuntimeDate·HTML 날짜 prepare·서버 날짜 적용·클라이언트 삽입 경로에서 공개 배포일을 차단한다. 기존 배포일 복제 source 표시에서 실제 페이지 확인 기록이 없으면 제거한다. 실제 source/camera/capture/link/modified 기록은 유지한다. 개별 출처 확인일을 페이지 전체 값으로 덮어쓰지 않는다. 운영용 날짜 JSON·서버 스냅샷·JSON-LD dateModified는 보존한다.
- 장소·이용 근거가 보존된 기존 사진 카탈로그를 정확한 상세/카메라 ID에 연결한다. 원 제작자·라이선스·출처는 유지한다. 카메라 참고사진의 공유 설명은 실제 카메라 화면이 아님을 명시한다. 기존 보관 사진 중 정확한 카메라 장소 ID에 연결된 참고사진도 사용하며 공유 이미지의 실제 사진가·라이선스·원출처를 본문 하단에 추가 표시한다. 확인되지 않은 사진과 유튜브 썸네일을 임의 재사용하지 않는다.
- 적합한 장소 사진이 없는 상세는 브랜드 OG/Twitter 이미지로 처리한다. 원래 본문에 있던 사진을 삭제하거나 바꾸지 않는다. 전체 URL 목록은 `docs/detail-image-exceptions-20261020.json`에 기록한다. 현재 로컬 2,246개 상세(기존 비지역 카메라 별칭 29개 포함) 중 장소 사진 선택 172개, 예외 2,074개다.
- 신규 상세도 공통 변환과 빌드/릴리스의 전체 HTML 감사에 포함한다. 사진 소스를 추가하면 이미지 카탈로그 생성 후 ID·장소·이용 근거를 검토해야 한다. 허브·목록·페이지네이션·저장/비교·서비스 정책 페이지는 상세 byline 대상에서 제외하며 공개 배포일 제거는 전체 HTML에 적용한다. 정본·hreflang·사이트맵·기존 링크는 유지한다.

## 검증과 증거 구분

SEO: 전체 생성 HTML의 제목·설명·H1·canonical·hreflang·robots·사이트맵 및 공유 메타 감사. 기존 길이 경고는 문장/조건 보존을 위해 유지하며 이번 작업에서 임의 절단하지 않는다.
AEO: 표시 저자와 조직 연결, 실제 FAQ와 설명 보존 검증.
GEO: 실제 사진/영상 제작자·원출처·검수 기록 보존 검증. ThaiLiveNow는 글·해설 저자이며 외부 미디어 제작자로 대체하지 않는다.
LLMO/NEO: 이번 변경의 실제 AI 인용·검색 수집/색인·순위는 측정하지 않았다. 배포 성공이나 구조화 데이터로 이를 보장하지 않는다.

전체 단위 테스트, 격리 소스 전체 빌드·SEO/날짜/편집 정책 감사, 변경 전후 URL·본문·미디어·링크·FAQ/미디어 주체 보존 비교, 실제 Pages 로컬 런타임, PC/모바일을 배포 전 확인한다. 로컬 결과물은 배포 완료가 아니다. 배포 뒤 운영 SHA·자산·지원 언어 응답과 preview noindex를 확인한 성공 결과물만 재사용 기준으로 승격한다. 상세 실행 증거와 최종 운영 검증은 `artifacts/editorial-policy-20261020/` 및 `artifacts/release-detail-editorial-*`에 보관한다.
