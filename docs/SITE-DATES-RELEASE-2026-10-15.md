# 공통 날짜 릴리스 기록

## 문서·기준 확인

- AGENTS, SEO·상세 템플릿·언어 설정, 기존 운영 배포 기록 및 실제 Wrangler 절차를 읽었다. GitHub 자동 workflow는 없다.
- 지정한 JapanLiveNow 로컬 참조 경로가 없어 GitHub의 `3cba29abd766283ca828e4df25c895fc4e98b56d`에서 요청한 9개 실제 파일과 검증 기록을 읽고 대조했다.
- origin/main은 초기 쉘 `bbd5278`이며 운영 콘텐츠는 다른 미커밋 작업이다. 작업 디렉터리의 기존 변경을 보존하고 별도 worktree에 이번 파일만 선별한다.

## 실제 구현

- 서버 날짜 JSON, Pages HTMLRewriter, 서버 응답 스냅샷과 Astro RuntimeDate/DOM 재렌더링 복구 모듈을 구현했다. 날짜-only 변경에서 HTML 대체 값은 고정된다.
- 11개 언어, 전체 HTML 1,816개 중 날짜 표시가 있는 1,699개에 표식 3,102개를 연결했다. 카메라 29개, 카메라 상세 348개(11개 언어 및 기존 별칭)를 포함한다.
- 자료 확인 기록 1,351개 페이지를 분리했다. 이 중 542개에는 실제 공통 확인 기록이 없어 null을 유지한다. 별도 페이지 기록이 없는 표시도 미확인이다.
- 카메라의 기존 확인일·장애/미검증 설명·관측 원문을 보존했다. 기존 기록에 정확한 분 단위 시각이 있는 3개만 ISO로 변환하고 원문·분 정밀도를 함께 보존했다. 시간 범위나 날짜만 있는 기록을 임의의 성공 시각으로 만들지 않았다.
- 실제 콘텐츠 수정일은 기존 데이터에서 발견되지 않은 경우 null이다. JSON-LD 2,959개는 원본 그대로 보존했다.
- npm postbuild에 날짜 테스트·생성·표식 적용·감사를 연결했다. 기존 SEO·빌드 관문을 유지했다. 신규 페이지 규칙과 AGENTS, 페이지 명세·템플릿·운영 문서에 연결했다.

## 로컬 검증

- 전체 Node 테스트 17개 통과. 기존 SEO 8개 및 날짜 9개.
- Astro 1,816개 빌드와 전체 SEO 감사: 오류 0, 제목·설명 중복 0. 기존 길이 등 경고 134개는 보존했다.
- 날짜 감사: 표식 3,102개, 오류 0. 초기 스크립트 삽입 위치가 SEO idempotence를 깨뜨리는 문제를 고쳐 전체 감사에 다시 통과했다.
- 성공 운영 배포 `2c56ab40`의 불변 URL에서 전체 1,816개 HTML의 제목·메타·본문을 기준 ZIP과 대조했다. 일시 DNS 실패 1개는 같은 URL 재조회 후 정상 일치했다.
- 운영 기준 자산에서 날짜 변경만 조립했다. HTML 1,816개, 기존 비HTML 자산 108개, JSON-LD 2,959개를 날짜 계약과 비교해 무관한 변경 0개였다. 신규 자산은 JSON·클라이언트 모듈·라우팅 세 가지다. Functions는 별도로 업로드한다.
- 실제 Cloudflare Pages 로컬 런타임에서 같은 HTML 해시로 JSON만 16일→17일 변경, 자료 확인일 유지, 잘못된 JSON·잘못된 날짜·누락에서 대체 값 보존, 기존 데이터·사이트맵·robots 유지에 통과했다. fixture 날짜는 운영 사실이 아니다.
- 브라우저에서 17일 서버 응답에 클라이언트가 1월 1일 대체 값을 다시 그려도 17일로 복구됐다. 현재 사이트에는 Preact hydration이 없으므로 DOM 재렌더링 계약을 시험했다.
- 11개 언어 대표 PC·모바일 44개 화면: H1 정상, 가로 넘침 없음, 카메라 확인일 10월 12일 유지. 존재하지 않는 Worldwide 공항 경로는 시험에서 제외하고 실제 카메라 경로로 확인했다.
- preview 호스트의 noindex 응답 및 데이터 실패 시 보호를 확인했다. API·자산·HEAD·302·404 불변은 회귀 테스트로 확인했다.
