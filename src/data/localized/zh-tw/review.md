## 시로코와 직접 비교

소개는 대상과 실제 보낼 시간을 연결했다. 예를 들어 목적지 첫 카드의 호텔 휴식 → 강변 식사/야경을 `白天在有泳池的飯店好好休息，晚上到河岸用餐，或上高空酒吧欣賞夜景。`로 옮겨 구체적인 장면과 동작을 유지했다. 여행시기에서는 비가 적다는 평가로 끝내지 않고 아침 사원/해질 무렵 강변/한낮 실내 휴식 순서를 남겼다. 입국은 여권·항공권·숙소 예약 자료 → 해당 칸 입력 → Preview/Edit → 이메일·동의·Submit → 성공 확인·파일 저장으로 이어지도록 썼다. 시로코의 예약·교통·짐·FAQ와 같은 행동 중심 설명 원칙을 적용하되 로맨틱한 식사 문구를 입국 안내에 복사하지 않았다.

금지/권장, 최대기간/실제 허가, 제출/승인을 구분했다. `不得`/`不能`에 해당하는 금지를 단순 권장으로 완화하지 않고, 입국심사와 비자 연장이 자동 승인된다고 쓰지 않았다. 번체 어순과 대만 여행 표현(飯店、護照、訂房資料、電子信箱、班號、觀景台)을 사용했다.
